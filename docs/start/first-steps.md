# 初めての方へ

## ログイン前に

おやさい鯖は**建築鯖**です！必ず、[ルール](../rules/rules-faq.md)を必ずお読みください

## ログイン方法

1. おやさいサーバーに対応したバージョンで起動します。
2. 次に、「マルチプレイ」→「サーバーを追加」をクリックしてください。
3. サーバー名は何でもOKです！「yasai」とかで大丈夫です。

- サーバーアドレスは「**oyasai.io**」です。
- 「完了」を押すと、サーバーが表示されます。

![](https://image01.seesaawiki.jp/o/i/oyasai/fef1bb74ca0e9aee.png)

4. 最後に、表示されたサーバーをクリックして「サーバーに接続」を押してログインです。

### Pocket Edition,Bedrock Edition(統合版)で接続・紐付けする方法

- おやさい鯖はPocket Edition(スマホ版)、Bedrock Edition(統合版)でもログインできます。
- iPhoneやAndroid、PS4・Xbox・Switchでも接続して遊べます。

☆詳しくはこちらのページをご覧ください。▶▶▶ [PE,BE(統合版)で接続・紐付けする方法](bedrock.md)

## サーバーに接続できない場合

※oyasai.ioで参加できない場合("Can't connect to server" や "Can't resolve hostname" 等と赤字で表示される)は、以下の理由が考えられます。

**サーバーアドレスを間違えて入力している**

- 「oyasai,io」はよくある間違いです。間違えて入力された際は、サーバーアドレスを確認するか、もう一度「サーバーを追加」から作り直してください。

**一時的にサーバーアドレスが変更されている**

- サーバーメンテナンス等の理由で、一時的に別のサーバーアドレスに変更されている場合があります。その際は、**おやさい鯖Discordに一時的なサーバーアドレスを配信します。**

**サーバーが落ちている**

- サーバーメンテナンス等の理由で、サーバーが落ちている可能性があります。サーバーの状況については、適宜おやさい鯖Discordで配信しますので、ご確認ください。

## ログインしたら

**おやさい鯖へようこそ！お金を貯めて、建築しましょう！**

1. サーバーに入ってから建築までの簡単な流れ ▶［鉱石採掘→鉱石売却→建材の購入→建築］◀

- 鉱石を掘ったら自動でお金が手に入ります。
- 掘った鉱石を売ることにより、また更にお金を入手できます。

2. <**/menu**>コマンドで取ってきた鉱石を売却しお金を得て建築をしよう！

**※資源及び鉱石はすべて資源ワールドで行ってください。**

### お金を稼ごう！

**お金稼ぎは、「資源ワールド」内の「鉱山ワールド」で鉱石を掘るのが効率がいいです。**

鉱石を採掘するために「**資源ワールド**」のゲートへ行きましょう。
「**鉱山ワールド**」へは資源ワールドへ入り、目の前の階段を降りるとテレポートできます。

![](https://image01.seesaawiki.jp/o/i/oyasai/bV1f4WR5lF.jpg)

<**/spawn**>で、ゲートエリアのあるロビーまで戻れます。

資源ワールドでは、基本的に全てのブロックが資材として採掘可能です。但し、資源ワールドのゲート付近は破壊しないで下さい。

#### 鉱石を売却するには・・・

1. <**/menu**>でメニュー画面を開く
2. 黄色のブロックから鉱石ショップを開く
3. 売りたい鉱石にカーソルを合わせ、右クリック

初期所持金は10,000円ですが、小規模の建築ならこのくらいの金額でも困りません。

- お金を貯める方法については、[経済要素](../play/economy.md)を参照して下さい。

## ☆建材を買おう！

お金がある程度貯まったら、建材を購入しましょう！
<**/menu**>でmenu画面を開きましょう。黄色いブロックがありますのでクリックし各項目から建材や装飾品などを購入してください。
また、鉱石の売買や魚の売却なども、全てmenu画面で行うことが出来ます。困ったらmenu画面です。

### 欲しい物がMenuショップに無い！

Menuショップに売られていないものでも、大抵は入手可能です。
中央商店街では、多種多様なアイテムを販売しています。

<**/spawn**>でスポーン地点に移動し、直進してください。
右前方に、中央商店街へのゲートがあります。
ブロック、作物、防具など、多種多様なアイテムが購入可能です。ぜひご利用ください。
各ショップについてはコチラのページをご覧ください。

**※お求めの物がない場合は、運営にご相談下さい。**

## 建築場所を決めよう！

基本どこに建築しても大丈夫です。ただし誰かが使ってそうな土地や、これから使いそうな土地のそばにはあまり建てないようにしましょう。

また<**/spawn**>でロビーに戻ったとき、ゲートから建築場所を探すときは**必ずゲート前の看板を読むように**お願い致します。
なるべく景観にあった建築を心がけましょう。

- 適当なゲートに入り<**/vtp**>と打てば空いてる土地にテレポートします。

### 建築場所が見つからなければ「**はじめて村**」がオススメです。

ここでは景観を無視して大丈夫なので好きな建築をしてみましょう！

- ただし1人１区画まで。ゲートが見つからなければ<**/sltp -8250**>とチャット欄に入力してください。
- １軒目以降は初めて村以外で建築してください。

## 建築場所を登録する

<**/sethome 好きな名前（英数字）**>のコマンドを使うことで現在地をホーム地点に設定します。
<**/home 登録した名前**>のコマンドで設定した地点にテレポートできます。

### 完成した建築を共有しよう！建築が完成したらlikes看板を立てましょう。

建築の適当な場所に看板を立て、**１行目に「likes」**、**2行目に「建築の名前」**と記入します。

![](https://image02.seesaawiki.jp/o/i/oyasai/tAfKWSPy0S.png)

※もちろん建築の名前は自由に変えられます。

これであなたの建築にみんなが簡単にアクセスできるようになりました！

## エンダーTTへの行き方

<**/spawn**>コマンドを打ち、最初の場所に戻ります。真っすぐ進み画像のところへ飛び込みます。
ポータルを潜り抜けたら看板に沿ってお進みください。
