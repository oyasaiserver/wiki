# おすすめMOD

Minecraft 現時点でおすすめmod紹介

* 当鯖ではチート系のmodは使用禁止です。発覚次第処罰されますので気をつけましょう。
  ここでは禁止MODは載せていません。（詳しくは[ルール](../rules/rules-faq.md)）
* 導入の際はすべて自己責任でお願いします。

## 前提mod

| 名前 | 説明 |
| --- | --- |
| [Fabric](https://fabricmc.net/use/installer/) | 様々なmodの前提mod |
| [Fabric API](https://modrinth.com/mod/fabric-api) | Fabricに必要なmod |
| [Iris Shaders](https://www.irisshaders.dev/download) | 影modの前提mod |

## 軽量化mod

| 名前 | 説明 |
| --- | --- |
| [EntityCulling](https://modrinth.com/mod/entityculling) | 見えていない部分のブロックやエンティティやらの処理を最適化 |
| [FerriteCore](https://modrinth.com/mod/ferrite-core) | メモリの使用量を節約してくれるmod |
| [ImmediatelyFast](https://modrinth.com/mod/immediatelyfast) | ゲーム内の様々な要素の描画処理を変更し、FPSを改善させるmod |
| [Lithium](https://modrinth.com/mod/lithium) | 多くのシステムを改善する軽量化mod |
| [ModernFix](https://modrinth.com/mod/modernfix) | メモリの使用量を削減し、パフォーマンスを向上させるmod |
| [Sodium](https://modrinth.com/mod/sodium) | 軽量化mod。これさえ入れとけば間違いない |
| [Sodium Extra](https://modrinth.com/mod/sodium-extra) | Optifineみたいに細かな設定ができる |
| [C2ME](https://modrinth.com/mod/c2me-fabric) | チャンクの読み込み方を変更して高速・軽量化するmod |
| [Dynamic FPS](https://modrinth.com/mod/dynamic-fps) | 放置など状況に応じてFPS値を下げてパソコンの負担を軽減してくれるmod |
| [BadOptimizations](https://modrinth.com/mod/badoptimizations) | 空の色や光の処理を最適化するmod |

## その他おすすめmod

| 名前 | 説明 |
| --- | --- |
| [Continuity](https://modrinth.com/mod/continuity) | ガラスなどのその他色々ブロックのつなぎ目を消すmod 導入するとリソースパックが2つほど追加されていると思うので追加して適応 |
| [Fusion](https://modrinth.com/mod/fusion-connected-textures) | Continuityと似たようなもの 別途でお好みのリソースパックを入れる必要あり |
| [Mod Menu](https://modrinth.com/mod/modmenu) | modメニュー画面を追加する。導入したmodの管理 |
| [Command Keys](https://modrinth.com/mod/commandkeys) | マクロmod |
| [WorldEdit CUI](https://modrinth.com/mod/worldedit-cui) | 火の粉よりもしっかりしたグリッド表示ができる |
| [Sodium Shadowy Path Blocks](https://modrinth.com/mod/sodium-shadowy-path-blocks) | Fabricだと土の道に影がつかないが、このmodを入れることにより以前のような影のついた土の道になる |
| [Simple Fog Control](https://modrinth.com/mod/simplefog) | 大気中の霧を除去する。Mod Menuで色々設定できます。 前提として[Cloth Config API](https://modrinth.com/mod/cloth-config)が必要 |
| [Logical Zoom](https://modrinth.com/mod/logical-zoom) | OptifineみたいにCキーを押すとズームする Cキーを押しても何もならないときはキー設定を覗いてみてください |
| [Zoomify](https://modrinth.com/mod/zoomify) | Logical Zoomと機能は同じだが視点が滑らず倍率を変えられる どっち使うかはお好みで |
| [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights) | 光源を手に持ったとき周囲を照らしてくれる |
| [BetterF3](https://modrinth.com/mod/betterf3) | F3を押したときいろいろな情報を色を付けて見やすくしてくれる |
| Chat Heads | チャットの名前横にその人のスキンヘッドを表示する |
| [Double Hotbar](https://modrinth.com/mod/double-hotbar) | ホットバーを2段にする。Rキーで切り替え 前提として[Cloth Config API](https://modrinth.com/mod/cloth-config)も入れてください |
| [3D Skin Layers](https://modrinth.com/mod/3dskinlayers) | スキンの立体化。カスタムヘッドも立体化する |
| [Distant Horizons](https://modrinth.com/mod/distanthorizons) | 描写距離を地平線の彼方まで広げてくれる |
| [Bobby](https://modrinth.com/mod/bobby) | ↑と似たようなもの |
| [AmbientSounds](https://modrinth.com/mod/ambientsounds) | 様々な音を追加してくれる音響mod。 前提として[CreativeCore](https://modrinth.com/mod/creativecore)も入れてください |
| [XPlus Autofish](https://modrinth.com/mod/x+-autofish) | 自動釣りMOD |
| [caramelChat](https://modrinth.com/project/M4vJe1FJ) | 日本語入力でも移動できるようになる |
| [Chat Patches](https://modrinth.com/mod/chatpatches) | 今までのチャットの履歴を残して検索出来るようにしてくれるmod 前提として[YetAnotherConfigLib (YACL)](https://modrinth.com/mod/yacl/versions?l=fabric&c=release)が必要 |
| [ChatShot](https://modrinth.com/mod/chatshot) | チャットをコピーできる |
| [Fabrishot](https://modrinth.com/mod/fabrishot) | 4Kスクショ、F9を押して撮影。Mod MenuとCloth設定を使って 解像度をデフォルト(3840x2160)から4Xに変更してください。 |
| [BedrockIfy](https://modrinth.com/project/ox3rDp1B) | クリエイティブモードでの飛行時の慣性（ドリフト）を無効にする 前提として[Fabric](https://fabricmc.net/use/installer/)[Fabric API](https://modrinth.com/mod/fabric-api)も入れてください |
