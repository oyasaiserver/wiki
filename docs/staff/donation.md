# 寄付

## 寄付のお願い

当サーバーは長らく「無料プレイ」を続けてきましたが、サーバー維持費などの負担が増えてきたため
このたび寄付をお願いすることになりました。皆さまのお力添えをいただければ幸いです。

Minecraftの[利用規約（EULA）およびエンドユーザー使用許諾契約書](https://www.minecraft.net/ja-jp/terms/r3)に従い、寄付していただいた方にゲームプレイで有利になるような特典を配布することはできません。

代わりに、ご協力いただいた方には専用のパーティクルエフェクトをご提供いたします。

## 寄付について(旧版)

当初より「無料プレイ」を一貫して参りましたが、サーバー維持費等の出費により、この度、寄付金を募ることとなりました。つきましては、誠に恐縮ではございますが、皆様方に本鯖発展に向けて格段のお力添えを賜りたく「寄付金のお願い」をさせていただきます。「寄付について」の内容も併せてご覧の上、なにとぞ御協力を賜りますようお願い致します。

Mojangの「Minecraftの商業目的使用に関するガイドライン（<https://account.mojang.com/terms#commercial>）」に則り、ゲームのプレイに関して有利に働く特典等を頒布する事は出来ません。当サーバの寄付受付はこれを遵守し、ご協力いただいた方には専用のパーティクルエフェクトを差し上げます。

寄付の形態に付き余しては、電子マネーにて受け付けております。Amazon Gift Cardでの寄付も受け付けておりますが、諸事情のため、Paypalにしていただけると幸いです。勿論、パーティクルエフェクトに差異はございません。

何卒、ご協力の程、よろしくお願い致します。
