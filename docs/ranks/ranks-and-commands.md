# ランクとコマンド

## ランクについて

おやさい鯖では、ランクによって使えるコマンドやできることが決まっています。
ランクを上げる方法は、もちろん**建築**です。
**クオリティも意識しながら建築をしましょう。ただ建てるだけではランクは上がりません。**

* 大体の目安はロビーから左前のゲート、住宅展示場をご覧ください。

※**太文字**のランクの色は、Discordでのランクの色に対応しています。

**・個人ワールドを所有できる。**

* 申請の際は鯖内の管理の人に言うか、Discord内の赤匠チャンネルで申請してください。
* ワールドの種類は［地形あり、フラット、VOID］
* ワールド初期サイズ半径150ブロック、投票ポイント100P使うことによって広さを50マスごと拡張できる。

**・Axiomサーバーについて**

* ホワイトリスト制なので参加したい方は運営にお声掛けください
* 参加する際はAxiomのmodを導入していないとAxiomは使えないので注意！
  DL先→&lt;https://modrinth.com/mod/axiom&gt;

## ロールについて

おやさい鯖の公式Discordでは、ランクなどに応じて個人にロールが付与されます。
ロールの付与は手動で行っているため、稀に間違ったロールの付与がされたり、MCIDとDiscord内のIDが一致せず付与されない場合があります。

その場合には、Discord鯖内チャンネルの「質問・要望」へ報告お願いします。
