# World Edit 依頼の仕方

World Edit (以下WE) は広範囲を破壊、大量のブロックを設置、巨大な球を生成する等が可能な本鯖のに便利プラグインです、
使用の依頼は **[運営]** **のみ**に許可されています。他の住人に依頼することは**禁止**です。
使用量は [100円 / 1ブロック] です。

依頼の際は、ステップを踏みましょう。

## ステップ１

指定したい範囲の始点、終点にピンクの羊毛を設置しましょう。

## ステップ2

**お金**を用意しましょう。**木の斧**で始点と終点を選択して、ブロックの数を数えましょう。

## ステップ3

運営を呼びましょう。呼び際には "**運営来い**”や "**WEして**"では無く、丁寧な言葉で話しましょう。
例："**今WE大丈夫ですか？**" "**後でWE依頼してもいいですか？**"

## ステップ4

建築をしよう！！
WEの依頼は初心者にとっては金銭的にもハードルが高いはずです。しかし、WEはあなたの建築ライフをもっと豊かにしてくれるでしょう。
