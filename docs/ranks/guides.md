# 案内モード

いつもお初さんの案内をしてくれている人に朗報！

初級の方を案内するとポイントがもらえる様になります！！

![](https://image02.seesaawiki.jp/o/i/oyasai/f511df3e67bd5e5f.jpg)

## 📋 案内モードの使い方

| 🔰 案内する人 | 🌱 案内される人 |
| --- | --- |
| 上級者以上のランクを持つプレイヤー | 初級ランクのプレイヤーのみ ※中級者以上は対象外 |

▶ 案内開始

`/annaimode <初級者の名前>`

→ チャットに【案内人】と表示されます

⏹ 案内終了

`/annaimode`（引数なし）

→ 案内人モードが解除されます

### 案内履歴の確認（上級者以上）

`/guidecheck <プレイヤー名>`

→ 誰が・いつ案内したかを確認できます

## 看板について

各エリアにある **[案内完了]** の看板を初級者に右クリックしてもらってください

- ✅ クリックごとに案内人へ10ポイント付与！
- ✅ 同じ看板は1人1回まで
- ✅ 違う初級者なら何度でも案内可能
