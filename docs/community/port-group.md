# PORT Group (ポート・ダイス市開発機構)

## ポート・ダイス市

市長： BBflat

テレポート： /sltp 1211

おやさい鯖のX=-135,Z=1237に位置する、潮風香る港町。  
南に海、北に広大な平原が広がる土地です。  
ダイス港を中心に、数々の匠や建築士の建築や、お野菜最大の地下商店街[Alpha's Port Avenue]は必見。  
港は勿論、OR線、三小メトロ線、大都市線（建設中）が通る鯖有数の都市です。

## 市民になりたい方

ポート・ダイス市は、厳密に区画分けされています。区画の中であれば、自由に建築して頂いて結構です。  
但し、ポートダイスは自治区です。鯖内のルールは勿論、特別なルールが存在します。詳しくは、法務省にお越しください。

## 開発計画

区画は大きく、特別区、西区、北区（開発中）に分けられています。特別区は上級者以上、西区は初心者優先となっています。  
特別区にそびえる匠、建築士や上級者達の建築を真似するのをおすすめしています。  
また、三小メトロ副都心線ポート・ダイス駅にはおやさい鯖最大の地下商店街 [Alpha's Port Avenue] が存在します。  
9x9の小さなスペースで内装を勉強するのも良いでしょう。
