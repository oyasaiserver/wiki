# 土地の保護について

木の斧で選択した範囲を保護できます。

## 土地の保護の方法

![](https://image02.seesaawiki.jp/o/i/oyasai/sWlgz0obf9.29.50.png)

木の斧を用意します

![](https://image01.seesaawiki.jp/o/i/oyasai/J4IA5RbEe7.18.36.png)

左クリックで最初の角を選択し、右クリックで最後の角を、最初の角と対角線で保護物を覆うように選択してください。

![](https://image01.seesaawiki.jp/o/i/oyasai/W_1gaDGp1B.55.32.png)

/region claim &lt;area name&gt;で土地の保護が完了です。

## 使用できるコマンド一覧

| コマンド | 説明 |
| --- | --- |
| 木の斧で指定して/region claim (土地の名前) | 土地の保護の作成する |
| /region remove (土地の名前) | 土地の保護を削除する |
| /region list | 保護している土地の一覧を表示する |
| /region addomember (土地の名前) (マイクラのID) | 土地の保護にメンバーを招待する |
| /region removemember (土地の名前) (マイクラのID) | 土地の保護にいるメンバーを排除する |
| 保護されている土地に立って/region info | 保護されている土地の情報を確認する |
