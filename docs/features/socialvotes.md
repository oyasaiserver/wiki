# SocialVotes

![](https://image02.seesaawiki.jp/o/i/oyasai/a057c86d7a42c852.png)

## SocialVotesとは

イベントなどで投票審査をするときにマイクラ内で投票システムを作れる独自プラグインです。  
SocialLikesと似たシステムを採用しています。

SocialVotesコマンド一覧

| コマンド | 説明 | 必要権限 |
| --- | --- | --- |
| /sv setgroup \<グループ名> | 投票用グループを作成する | 誰でも可 |
| /sv add \<グループ名> | SV看板をグループに登録する | 誰でも可 |
| /sv remove | SV看板をグループから除外する | オーナー、OP |
| /sv list | 存在するグループの一覧を開く | 誰でも可 |
| /sv list \<グループ名> | グループに属するSV看板の一覧を開く | 誰でも可 |
| /svtp \<ID> | そのIDのSV看板にテレポート | 誰でも可 |
| /svupdate | 移動させたSV看板の座標を更新する | 誰でも可 |
| /sv startvote \<グループ名> | 強制的に投票開始する | オーナー、OP |
| /sv stopvote \<グループ名> | 強制的に投票終了する | オーナー、OP |
| /sv delhere | 実行者の足元のSV看板を削除する | OP |
| /sv allclear \<グループ名> | そのグループに関する情報を全消去する | OP |

※delhere、allclearは取り返しがつきません。慎重に行って下さい。  
※delhere時にその看板がグループに属する最後の看板であった場合、グループは自然消滅します。

## 使い方(投票者向け)

### SV看板を作る場合

投票先の前など分かりやすい場所などに看板を設置し、

- 以下の通り入力**１行目に「vote」、２行目に建築名や組織名(お好き名前で)**
- 3、4行目には何も書かないでください。

※SocialLikesでは**「likes」**、SocialVotesでは**「vote」**なので気を付けて！  
![](https://image01.seesaawiki.jp/o/i/oyasai/d5442f86c4e150f6.png)  
設置完了すれば完成です！

### 投票する場合

看板を右クリックすることで、その投票先に票を送ることができます！  
自身の投票を取り消したいときは、シフト+右クリックから画像の項目を押して下さい。  
![](https://image01.seesaawiki.jp/o/i/oyasai/800aec045d1efdf7.png)  
その他にも看板制作者は以下の項目を編集できます。

- 建築名・組織名を変更する(看板２行目の表示)
- 制作者名を変更する(看板３行目の表示)
- 制作者の追加・除外

## 使い方(投票管理者向け)

### 投票のはじめ方

投票審査を実施する際は、新しく投票用のグループを作成する必要があります。  
複数部門がある場合、各部門用のグループを作成することをおすすめします。

グループの作成・登録

### グループの作成

以下のコマンドでグループを作成します。

- /sv setgroup \<グループ名>

※既に存在するグループ名は使えません。

> **補足**  
> このとき、あなたはそのグループのオーナーとなります。  
> グループの設定操作はオーナー以外できません。  
> (OPはオーナーと同じ権限を持つので操作可能です)

### グループへの登録

以下のコマンドを実行後、SV看板をクリックすることで登録します。  
※SV看板以外のブロックをクリックするまで登録状態が続きます。

- /sv add \<グループ名>

グループへの登録は誰でもできるので、SV看板制作者に登録を任せても構いません。  
**一つのグループへのSV看板最大登録可能数は45個です。**

投票形式の設定

簡易GUIの一番右の項目から詳細設定GUIに飛べます。  
基本は下の薄赤色背景の項目を任意に設定すれば大丈夫です。

### 詳細設定GUIでできること

- 得票数の公開・非公開の切り替え(グループ全体・看板単体で設定可)
- 一つの看板に投票できる数の設定(デフォルト：１) ...
- グループ全体に投票できる数の設定(デフォルト：１) ...
- 投票開始・終了時刻の設定
- 全プレイヤーの投票リセット
- 看板・グループの消去

※の数をの数より多く設定すると矛盾が生じるため、の数に強制されます。  
![](https://image02.seesaawiki.jp/o/i/oyasai/20e5b2b7bbe5b03b.png)

### 投票期間終了後の操作

詳細設定GUIから投票結果に進むことで、グループに属する看板の投票結果が確認できます！  
また、投票結果画面から看板をクリックすることで、その看板の投票者も確認できます。

### 投票結果画面

![](https://image01.seesaawiki.jp/o/i/oyasai/e1bcd837c41d1be6.png)  
↑左下のホッパーから並べ替えができます。

### 投票者一覧画面

![](https://image01.seesaawiki.jp/o/i/oyasai/2e28696fbe1f5358.png)  
↑同じく左下のホッパーから並べ替えができ、矢でページ移動ができます。
