# 機能・プラグイン

おやさいサーバー独自の機能と、その使い方。

- [バックパック](backpack.md) — 全員が持つ持ち運び用の収納
- [DynamicProfile](dynamicprofile.md) — 自己紹介・称号・おすすめ建築の設定と順位確認
- [SocialLikes](sociallikes.md) — 建築物にイイネを付ける看板プラグイン
- [SocialVotes](socialvotes.md) — イベント用の投票システム
- [CarBuilder2](carbuilder2.md) — 自作の車を作って運転できるプラグイン（旧版の記述つき）
- [車種一覧](car-list.md) — 制作者別の登録車両
- [エレベータープラグイン](elevator.md) — エレベーターの作り方と設置の決まり
- [おえかきマップ](drawing-map.md) — 地図に絵を描く機能
- [OyasaiMusic](oyasaimusic.md) — 楽曲の録音・試聴・レコード・環境BGM
- [OyasaiPets](oyasaipets.md) — ペットプラグイン（旧ペットプラグインの記述つき）
- [EntityPose](entitypose.md) — アーマースタンドや動物を配置・操作する建築補助
- [CitiesSkyMine](citiesskymine.md) — 窓・坂道・柱・ベジェ曲線などの建築補助コマンド
- [家具について](furniture.md) — 家具プラグイン（現在は消滅）
