# OyasaiMusic

![](https://image02.seesaawiki.jp/o/i/oyasai/a0db041f0021b10c.png)

## OyasaiMusicとは

音符ブロックの演奏を楽曲として保存し、サーバー内で試聴・いいね・プレイリスト登録できるプラグインです！  
制作した曲はレコードにして、ジュークボックスから環境BGMとして流すこともできます。

## はじめかた（聴く人向け）

### メニューを開く

- **/mm** (/musicmenu) を実行する
- または **/getmp** (/getmusicplayer) で音楽プレイヤーを受け取る

音楽プレイヤーは、右クリックで前回の画面、Shift+右クリックでメインメニューを開きます。

### 楽曲を探す・再生する

メインメニューから、検索・全楽曲一覧・ランキング・お気に入り／プレイリストを開けます。  
楽曲の題名の近くにはIDが表示されます。コマンドから直接開くこともできます。

| コマンド | 内容 |
| --- | --- |
| /mm play \<ID> | 指定した楽曲をすぐ再生する |
| /mm open \<ID> | 楽曲詳細を開き、同時に再生する |

楽曲詳細では、試聴・いいね・お気に入り登録・プレイリスト追加ができます。  
公開前の楽曲は、作者本人と管理者だけが確認できます。

### 再生中の表示と操作

- 曲名と再生進捗は画面上のボスバーに表示されます。
- 個人再生中は、再生している本人の頭上に音符パーティクルが表示されます。
- GUI下段から、一時停止、前後の曲、シャッフル、ループを操作できます。
- 曲の切替は0.75秒後に行われます。

## GUIのクリック操作

楽曲一覧などのアイテムには、クリックごとの動作がloreに表示されます。

| 操作 | 楽曲一覧での基本動作 |
| --- | --- |
| 左クリック | 再生 |
| Shift左クリック | 詳細を開く |
| 右クリック | いいね |
| Shift右クリック | お気に入り／プレイリストへ追加 |

統合版では左タブの「アクションモード切り替え」から、同じ4操作を選んで実行できます。

## レコードと環境BGM

楽曲詳細からレコードを購入できます。レコードを持ってジュークボックスを右クリックすると、環境BGMとして設置できます。

- レコードは設置時に消費されます。
- 手ぶらでジュークボックスを右クリックすると、再生を停止してレコードを取り出せます。
- レコードをShift+右クリックすると、再生範囲・トリガー・ループを設定できます。
- 環境BGMの再生中は、聴いているプレイヤーではなくジュークボックスの上にだけ音符パーティクルが表示されます。

新規レコードの再生範囲は半径16ブロックです。再生範囲は権限ごとに個別に許可され、設定画面では自分に許可された範囲だけを選べます。権限外の範囲が設定済みのレコードも、ジュークボックスへの設置時には使えません。

| 再生範囲 | 必要権限 |
| --- | --- |
| 半径16ブロック | 中級 |
| 半径64ブロック | 上級 |
| 半径256ブロック | 建築士 |
| ワールド全体 | 赤匠 |

| トリガー | 動作 |
| --- | --- |
| ジュークボックス | 設置と同時に再生 |
| RS信号 | ボタンなどの入力ごとに再生／停止を切替 |
| 接近 | 設定範囲にプレイヤーが入ると再生 |

## 楽曲を作る（制作者向け）

### 録音方法

| 方式 | 使い方 | 用途 |
| --- | --- | --- |
| グリッド型 | /rec we grid \<BPM> | 等間隔に置いたノートブロックの譜面を視点の向きを進行方向として録音 (おすすめ録音方法) |
| 回路型 | /rec we default | コピーした回路を解析して録音(不安点 非推奨) |
| 生演奏 | /rec live → 演奏 → /rec stop | 実際に手などで鳴らした音をそのまま録音 |
| 現地回路録音 | //copy → /rec we start \<RS tick> → 回路を起動 → /rec stop | 実際の回路の発音を録音 |

※RS tick とは、リピーターの1遅延を基準とする単位です。  
※生演奏録音以外は先にFAWEの範囲選択で囲み、コピーする必要があります。

現地回路録音のRS tickは、0.5 / 1 / 2 / 3 / 4 から選びます。  
1RS tickは0.1秒です。指定した単位へ時刻を丸めるため、サーバーラグによる細かなずれを抑えられます。  
値はリピーター遅延の最小値をお選び下さい。

録音完了後は楽曲設定画面が開きます。題名、BPM、レコード種類、価格、参考URL、公開状態を設定してください。

### ノートブロック制作を補助するおすすめ導入（任意）

ノートブロックの音階・音色を見ながら回路を組みたい場合は、次の導入をおすすめします。  
OyasaiMusicの利用に必須ではありません。  
導入可能なMinecraftバージョン・ローダーは、各配布ページを確認してください。

- [Note Block Tweaks](https://modrinth.com/resourcepack/note-block-tweaks)（リソースパック）
    - ノートブロック音楽制作用の表示補助リソースパック
- [Note Block Tuner](https://modrinth.com/mod/note-block-tuner)（Fabric・クライアントMod）
    - 現在の音階・音色を表示するGUIから、音階を選んで自動調律できるMod
    - マルチプレイでもクライアント側だけで動作します。

### 公開と審査

- 録音直後の曲は非公開の下書きです。
- 公開をONにすると、一般の一覧・検索・ランキングに表示されます。
- オリジナル審査は公開後に提出できます。提出時は仮OKとなり、管理者が許可／未審査／却下を判定します。
- 参考URLの登録またはオリジナル審査の申請で、視聴ポイント・レコード売上の作者還元を受け取れる収益化対象になります。

## 報酬と収益化

参考URLを登録した楽曲、または公開後にオリジナル審査を申請して仮OK以上になった楽曲は、**収益化対象**です。  
参考URL登録・オリジナル審査申請のどちらか一方で条件を満たします。

| 種類 | 発生条件 | 初期設定の報酬 |
| --- | --- | --- |
| いいね報酬 | 公開楽曲へ未いいねのプレイヤーがいいねする | 作者: 2pt / 送信者: 1000円 |
| 視聴報酬 | 収益化対象の楽曲で有効な視聴が合計10回に到達するごと | 作者: 1pt |
| レコード売上 | 収益化対象の楽曲のレコードを購入する | 作者: 購入額の80% |

いいねは公開楽曲だけに付けられ、同じプレイヤーによる重複いいねはできません。  
いいねによるポイント収入は、収益化条件を満たしていない楽曲にも付与されます。

視聴が有効として数えられるには、特定の条件を満たす必要があります。  
(条件は原則非公開とします。)

報酬は未受取残高へ蓄積され、トップメニューの「未受け取り報酬を受け取る」から受け取れます。

### 楽曲設定から音源を作り直す

設定画面の「FAWEクリップボードを再読み込み」では、4つの操作を使い分けられます。

| 操作 | 方式 |
| --- | --- |
| 左クリック | グリッド型（現在のBPMで即時上書き） |
| Shift左クリック | 生演奏録音を開始。/rec stopで上書き |
| 右クリック | 現地回路録音を開始。/rec stopで上書き |
| Shift右クリック | 回路型（即時上書き） |

現地回路録音は、直前に指定したRS tickを引き継ぎます。未指定なら1RS tickです。  
回路を押す前なら、/rec we start \<RStick> で変更できます。

## 看板による音の調整

ノートブロックの真上に看板を置くと、録音時の音を調整できます。

| 行 | 内容 | 例 |
| --- | --- | --- |
| 1行目 | 音量（0〜100） | 80 または 80% |
| 2行目 | Pan（-100〜100） | -50 |
| 3行目 | 発音ずらし | 1/2、-2/5 |
| 4行目 | バニラSoundEvent ID | 4.5.1:2 |

3行目は、1を1拍分遅らせるとして、1/2で半拍分遅らせられます。正の値は遅らせ、負の値は早めます。  
4行目を指定すると、ノートブロック本来の音色を指定したバニラ音源へ置き換えます。ピッチは下のノートブロックを使います。

/demosound \<SoundEvent> \<パターン> [ピッチ] で、看板用音源を自分だけで試聴できます。  
実行結果のIDはクリックでコピーできます。

## よくある質問

### Q. 録音時にクリップボードが見つからない

A. FAWEで範囲を選択してから //copy を実行してください。グリッド型・回路型・現地回路録音で必要です。

### Q. 曲が一覧に出ない

A. 楽曲設定で「公開中」に切り替えてください。下書きは作者本人と管理者だけに表示されます。

### Q. レコードを置いたのに音が聞こえない

A. レコードの環境BGM設定にある再生範囲・トリガーを確認してください。RS信号トリガーは、信号を入れた瞬間に再生／停止を切り替えます。

### Q. データをバックアップしたい

A. 管理者は **plugins/OyasaiMusic/database.db** と **plugins/OyasaiMusic/audio** を必ずセットで保存してください。
