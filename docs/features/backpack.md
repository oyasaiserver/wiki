# バックパック

## バックパックとは

バニラにおけるシュルカーボックスのように、多くのアイテムを運搬可能にするシステムです。  
全員が初期装備として一人一つ所持しています。手放すことはできません(チェストにしまう、捨てるなど)。

## 使い方

1. チャット欄に\</bp>と入力します。
2. バックパックが開きます。
　![](https://image02.seesaawiki.jp/o/i/oyasai/81e3865c870715d1.png)

3. ドラッグ＆ドロップでアイテムを出し入れすることができます。
4. インベントリを閉じて完了です。
