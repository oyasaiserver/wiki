# DynamicProfile

## DynamicProfileとは

DynamicProfile（以下DP）は、自己紹介や称号、自分の建築をおすすめに登録出来たりします。  
おすすめ建築は定期的に他のユーザーに宣伝してくれるので、自分のスタイルや作品をもっと多くの人に知ってもらえるチャンスが広がります。

## 使い方

チャット欄に\</dp>と打ちます  
![](https://image02.seesaawiki.jp/o/i/oyasai/f4208fc0b5548f36.png)

このような画面が出てくるのでここから色々確認・設定していきます。

#### 自分の顔

カーソルを合わせると簡単な詳細。クリックするとより細かな詳細を見ることが出来ます。

#### おすすめ建築

紙のアイコンのところで色々設定できます。  
DPで自分の建築をおススメに登録すると、定期的に宣伝されます！

- 統合版は以下のように設定してください。
    - 設定：/dpsuki add \<スロット0~4> \<SLID>
    - 削除：/dpsuki remove \<スロット0~4>

#### 称号

吊り看板のところから称号を設定できます。  
説明が付いてるのでどういう称号かわかりやすいです。

#### 自己紹介

自由に自己紹介を書き込めるようになりました！ユーザー一覧画面でも自己紹介が表示されます。  
左下の本のアイコンから設定可能です。

#### ベル・チェスト

- ベル・・・レベルアップの通知 ON / OFF
- チェスト・レベルアップの報酬受け取り

#### プレーヤーヘッド

鯖内にいる人が一覧で表示されます。  
相手のプロフィール画面からお金やポイント、更にはアイテムも渡せたり\</tpa>のリクエストを送れたり出来ます。

### 以下のコマンドを打つといろんな順位を確認できます

| /dpl levele | レベル |
| --- | --- |
| /dpl chat | チャットした回数 |
| /dpl like | いいねした回数 |
| /dpl relike | いいねされた回数 |
| /dpl move | 移動した距離 |
