# SocialLikes

![](https://image02.seesaawiki.jp/o/i/oyasai/u_XvIvgFj2.png)

## SocialLikesとは

建築物にイイネを付けられるようになる独自プラグインです。  
また、イイネされるとポイントショップで使えるポイントが2ポイントもらえます。

開発者

- SocialLikes v1 [Kai\_Z\_JP](https://github.com/Kai-Z-JP)
- SocialLikes v2 [eru\_\_chan](https://github.com/shunueda)
- SocialLikes v3 [Srain3](https://github.com/Srain3)

## 使い方

出来あがった建築の分かりやすい場所に看板を設置して、

- 以下の通り入力**１行目に「likes」、２行目に建造物の名前（お好きな名前で）**
- 3、4行目には何も書かないでください。

![](https://image02.seesaawiki.jp/o/i/oyasai/tAfKWSPy0S.png)  
設置完了すれば完成です！

看板を右クリックすることで、その建築物に「いいね」を送ることができます！  
自分の建築に「いいね」が押されると、アクションバーでのメッセージと通知音でお知らせします。

### 建築物を見る！

SocialLikesの看板が設置されると、チャットでメッセージが送られます。  
チャットを開き、「クリックでテレポート」をクリックすると、看板の建てられた場所にテレポートできます。

## 多彩な機能

#### 便利な機能１

看板をシフト＋右クリックすると今までイイネしてくれた人を確認出来る！  
![](https://image01.seesaawiki.jp/o/i/oyasai/MjGH3kewJq.png)

#### 便利な機能２

一番下の項目では建築を宣伝出来たり、看板のデザイン変更や移動なども出来ます。

- 看板：10Pを消費してオンラインプレイヤーに宣伝する。
- プレイヤーヘッド：その人の建築一覧
- エンダーチェスト：詳細設定、自分のLikes看板の設定を開く
    - 例：看板のデザイン変更や移動や消去など

#### 便利な機能3

気に入った人をフォロー出来る！  
やり方

1. しゃがみながら看板を右クリックし、作った人の顔をクリック
2. 右下にあるトーテムをクリックすれば完了です
![](https://image01.seesaawiki.jp/o/i/oyasai/9GYIQhX7DU.png)　![](https://image02.seesaawiki.jp/o/i/oyasai/hLUTfaWajn.png)

### フォローした時のメリット

- フォローすればその人の建築見つけなくてもいつでも見に行くことができます。
- フォローした人は\</slmenu>と入力した画面からフォロー一覧を開き、トーテムをクリックすることで確認が可能です。

## 観光にも使える

看板をシフト+右クリックで出せる画面の右下のアイコン（紙）にカーソルを合わせると「設定(ID:xxxx)」という文字が表示されます。  
※[xxxx]には各建築に割り振られた数字が入ります。  
/sltp [xxxx]というコマンドを打つとその数字が割り振られている建築にtpできます。

## SLTP看板

SLTP看板とは、クリックすると**紐づけられたSL看板にテレポート出来る特別な看板**です。  
建築紹介や、ワープ拠点の設置などに便利です！

#### 入手方法

取得コストとしてクリエ権限持ちは100ポイント、それ以外の方は50ポイントかかります。

1. テレポート元のSL看板の【詳細設定】を開き、【SLTP看板を入手する】をクリック。
2. インベントリに収納させるので置きたい場所に置いて完成です。

![](https://image02.seesaawiki.jp/o/i/oyasai/baf6f2700b6c40cc.png)

間違って置いてしまった場合\<**/slsignbreak**>で回収可能です。

- SLTP看板の色は元のLikes看板に依存します。
- クリエ権限を持つ方は、看板を複製しても構いません。
    - 複製したSLTP看板はすべて同一のSLIDにリンクされます。
