# おえかきマップ

## おえかきマップ(Canvas)

**ゲーム内でおえかき**ができる機能です。  
使い方はシンプル！ 地図(Canvas)に染料を使って描けます。  
おやさいオリジナルプラグイン!! 作者:Srain3 ([Github](https://github.com/Srain3))

### つかいかた (基本)

「表現の自由」をポイントショップから購入しよう！(おえかき権限の購入です)  
![](https://image01.seesaawiki.jp/o/i/oyasai/g7hOGImbnG.png)

[Canvas: \<ID>]という名の地図がキャンバスです。\<ID>の部分は自動で割り当てられています。  
この地図を額縁に飾るとキャンバスとして機能します。

後は簡単！各色の染料でキャンバスを右クリックすれば描ける！  
(GIFを導入)

一度「表現の自由」を購入すれば新しいキャンバスの取得などは無料です。  
/menu の旗の模様アイテムをクリックで新しいキャンバス取得です。  
![](https://image02.seesaawiki.jp/o/i/oyasai/FIL31I9DmV.png)

/menuから取得した時についてくるシュルカーボックス内に専用ペン(アイテム:羽)が付属しています。  
専用ペンはRGB値を直接指定してCanvasに描けるペンで、0~255と#FFFFFF(16進数)の記述に対応しています。  
設定は左クリックで開く金床で行えますのでぜひ使って下さい！

### つかいかた (コマンド)

| コマンド | 説明 |
| --- | --- |
| /painttools brushsize \<0〜20> | ブラシサイズを変更する。 1+(size×2)px 例: 0=1px / 2=5px /10=21px /15=31px |
| /painttools canvas | 新しいキャンバスのみを取得 |
| /painttools canvas \<ID> | 指定されたIDのキャンバスを取得 |
| /painttools lock \<ID> | 指定されたIDを上書き禁止にする |
| /painttools unlock \<ID> | 指定されたIDのロックを解除する |
| /painttools undo \<1〜3> | 目の前のCanvasを1〜3分前に戻す もし失敗しても戻せます |

### おまけ

使用、設置のキー割当を右クリックではなく任意のキーに設定すると超描きやすくなります。
