# EntityPose

![](https://image02.seesaawiki.jp/o/i/oyasai/46f58ff36752e5fe.png)

EntityPose（エンティティポーズ）とは、アーマースタンドや動物を自由に配置・操作できる建築補助プラグインです。  
製作者: ankokun\_san / 公開日: 2026年4月6日

**建築士以上**のプレイヤーが利用できます。

## はじめかた

1. **/ep stick** でエンティティ棒を入手する
2. エンティティ棒でブロックを左クリックしてエンティティスポーンGUIを開く
3. エンティティを選択してスポーンさせる
4. 視線に追従するエンティティを好きな場所に置き、右クリックで固定する

**GUIからスポーンさせられる対象は、アマスタ / ミニアマスタ / オオカミ / ネコ / ウサギ / オウムです。**  
**AIが有効なエンティティは編集を拒否される場合があります。**

## 基本操作

| 操作 | 方法 |
| --- | --- |
| コマンド、操作一覧を表示 | /ep |
| エンティティ棒を入手 | /ep stick |
| エンティティをスポーン | エンティティ棒でブロックを左クリック |
| エンティティを視線追従 | エンティティ棒で右クリック |
| エンティティ情報を表示 | /ep info |
| エンティティ設定GUIを開く | /ep infoset |
| コピー用ワンドを入手 | /ep wand |

## コマンド一覧

全てのコマンドは/ep 〜です。

| コマンド | 説明 |
| --- | --- |
| /ep | コマンド一覧と操作ガイドを表示 |
| /ep stick | エンティティ棒を入手 |
| /ep info | 視線の先のエンティティ情報を表示 |
| /ep infoset | 視線の先のエンティティ設定GUIを開く |
| /ep kakudo [角度] | 角度の刻み幅を変更（0.5〜90.0、引数なしでGUIを開く） |
| /ep zahyo [値] | 座標の移動量を変更（0.01〜2.0、引数なしでGUIを開く） |
| /ep scale \<0.3〜3.0> | 視線の先のエンティティのサイズを変更 |
| /ep hojo \<on/off> | 空中操作時の補助足場表示を切り替える |
| /ep wand | Entity Copy Wand を入手 |
| /ep copy | 選択範囲のエンティティをコピー |
| /ep paste | コピーしたエンティティを貼り付け |
| /ep cut | 選択範囲のエンティティを削除 |
| /ep clear | 選択範囲を削除 |

**※ エンティティ棒（ブリーズロッド）と Entity Copy Wand（エコーシャード）は別アイテムです。**

## よくある質問

### Q. 棒でエンティティを操作しようとしても反応しない

A. まず **/ep stick** で専用のエンティティ棒を入手してください。対象がロックされている、AIが有効である、または権限がない場合も操作できません。

### Q. エンティティをスポーンするには？

A. エンティティ棒を持ってブロックを左クリックすると、エンティティスポーンGUIを開けます。

### Q. コピー用の棒は同じですか？

A. 別です。**/ep wand** で Entity Copy Wand を入手してください。

### Q. バグ・追加リクエストはどこに報告する？

A. Discord の **#質問・要望** チャンネルにお知らせください。

**※ 他プレイヤーのエンティティを無断で操作・削除しないようにしてください。**
