おやさいサーバー独自の機能と、その使い方。

- [バックパック](/features/backpack/) — 全員が持つ持ち運び用の収納
- [DynamicProfile](/features/dynamicprofile/) — 自己紹介・称号・おすすめ建築の設定と順位確認
- [SocialLikes](/features/sociallikes/) — 建築物にイイネを付ける看板プラグイン
- [SocialVotes](/features/socialvotes/) — イベント用の投票システム
- [CarBuilder2](/features/carbuilder2/) — 自作の車を作って運転できるプラグイン（旧版の記述つき）
- [車種一覧](/features/car-list/) — 制作者別の登録車両
- [エレベータープラグイン](/features/elevator/) — エレベーターの作り方と設置の決まり
- [おえかきマップ](/features/drawing-map/) — 地図に絵を描く機能
- [OyasaiMusic](/features/oyasaimusic/) — 楽曲の録音・試聴・レコード・環境BGM
- [OyasaiPets](/features/oyasaipets/) — ペットプラグイン（旧ペットプラグインの記述つき）
- [EntityPose](/features/entitypose/) — アーマースタンドや動物を配置・操作する建築補助
- [CitiesSkyMine](/features/citiesskymine/) — 窓・坂道・柱・ベジェ曲線などの建築補助コマンド
- [家具について](/features/furniture/) — 家具プラグイン（現在は消滅）
