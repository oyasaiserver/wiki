画像を地図にして飾り、額縁を保護できます。

利用できる機能とランクの対応は未確認です。使えない操作は運営へ確認してください。

## 画像を地図にする

`/tomap <URL> [resize [幅 高さ]]` に、画像の直接リンクを指定します。利用できる形式は PNG、JPEG、GIF、WebP です。URL は小文字の `http://` または `https://` で始めてください。画像ページでは取得できない場合があるため、画像ファイルの直接リンクを使ってください。

- `/tomap URL` は画像の縦横比に合わせて地図を並べます。
- `/tomap URL resize` は 1×1 枚に収めます。
- `/tomap URL resize 幅 高さ` は指定した列数・行数に収めます。幅と高さは正の数です。画像は枠内に収まるよう縮小・拡大され、縦横比は保たれます。

通常は、1画像あたり最大100枚の地図です。動く GIF は標準で最大16枚分の大きさ（横の枚数×縦の枚数）、60コマ、作成に使う地図500枚です。1人が持てる動く画像の地図は合計2000枚で、一覧から隠した画像も数えます。サーバー側の設定や権限で上限が変わる場合があります。resize なしの大きな画像は地図枚数の上限に収まるよう自動縮小されます。resize で上限を超える枚数を指定すると拒否されます。動く GIF も同様です。取り込みに成功すると、ポスター用の地図が持ち物に入ります。持ち物に入らない分は足元に落ちます。

取得する画像ファイルは16 MiB以下にしてください。画像は縦横それぞれ8192ピクセル以下、総画素数2500万以下である必要があります。非公開ネットワークのアドレスや標準以外のポートへの接続は拒否されます。

近くにいる全員への動く画像地図の送信には、閲覧者ごとに接続中3000枚の上限があります。ログアウト、ワールド移動、リスポーンで送信状態がリセットされます。近くの誰かが地図を受け取っていない間は、ポスターが最初のコマのままになることがあります。

### 自分の画像を見る

`/tomap list` で画像一覧を開きます。

- 左クリックで画像を受け取ります。
- 右クリックで確認画面を開き、「非表示にする」を選ぶと自分の一覧から隠します。隠した画像をプレイヤー側から一覧へ戻す操作はありません。間違えて隠した場合は運営に相談してください。
- 一覧は1ページ45件です。前後のページへ移動できます。

`/tomap info` は、見ている額縁か手に持っている地図の情報を表示します。額縁を調べるときは5ブロック以内から見てください。

## ポスターを貼る・外す

1. 画像の地図を手に持ちます。
2. 貼りたい面の左下になるブロックを、その面を向いて右クリックします。壁・床・天井に貼れます。
3. ポスターの大きさ分、後ろに固いブロックがあり、前にブロックや額縁・絵画がない場所を選びます。

地図は消費しません。額縁を直接右クリックして貼ることはできません。チェストやドアなど右クリックで開くブロックに貼るときは、しゃがみながら右クリックしてください。貼ったポスターは透明な額縁に表示されます。

ポスターを見ながら `/tomap remove` を実行すると外せます。5ブロック以内から額縁を見てください。通常のポスター額縁は取り除かれ、額縁アイテムは返りません。旧版から引き継いだポスターは、画像だけ外れて額縁が残ることがあります。

- `/tomap glow` は、見ているポスターを普通の額縁・輝く額縁の間で切り替えます。
- `/tomap glow on` / `/tomap glow off` は、これから貼るポスターの額縁を選びます。切り替えは以降に貼るポスターに適用されます。

額縁ロックが有効な場合、貼った人がポスター額縁の持ち主になります。管理ポスターは持ち主でも通常の破壊では外せず、ロック解除後も同じです。外すには `/tomap remove` を使ってください。

remove と、見ているポスターへの glow は、対象として見つかった全額縁の条件を先に確認します。ロック済みなら自分が持ち主であること、ロックされていなければその場所に建築できることが必要です。自分のロックがある額縁では建築権限を確認しません。1枚でも条件を満たさないと操作全体が拒否されます。

## 額縁をロック・透明化する

額縁を置くと自動でロックされます。既に置かれた額縁をロックするときは、`/gakubuchilock on` を実行してから額縁を右クリックします。終わったら `/gakubuchilock off` を実行します。短縮形は `/glock` です。

自分がロックした額縁を解除するには、`/gakubuchiunlock on` の後に額縁を右クリックし、終わったら `/gakubuchiunlock off` を実行します。短縮形は `/gunlock` です。別の人がロックした額縁は解除できません。

- `/gakubuchitoumei on` の後に額縁を置くと、自動で透明になります。終了は `/gakubuchitoumei off` です。短縮形は `/gtoumei` です。
- `/gakubuchifinder` は近くの自分の透明なロック済み額縁を赤いパーティクルで10秒間示します。範囲の既定値は32ブロックです。`/gfinder 64` のように指定でき、範囲は1～100ブロックです。
- `/toumeigakubuti`（`/toumei`、`/invisibleframe`）は、見ている額縁の透明・表示を切り替えます。8ブロック以内の額縁が対象です。

ロックや透明化のモードはログアウトすると終了します。モードを切り替えるときは、前の操作が終わったことを表示で確認してください。

地図に絵を描く操作は、[おえかきマップ](/features/utilities/#おえかきマップ)をご覧ください。

## 困ったとき

| 表示 | 意味・次にすること |
|---|---|
| `権限がありません` / `このコマンドを使用する権限がありません。` | その機能を使う権限がありません。運営に確認してください。 |
| `混雑しています` | 画像の取り込み処理が混み合っています。時間をおいて再実行してください。 |
| `画像を作成できません: 通信または保存に失敗しました` | 画像を取得・解析・保存できませんでした。直接リンク、画像形式、画像サイズを確認してください。 |
| `画像を作成できません: <理由>` | 取得や画像の制限に該当しました。表示された理由を確認してください。 |
| `コマ数が多すぎます（<コマ数> コマ、上限 <上限> コマ）` | 動く GIF のコマ数を減らしてください。 |
| `地図が多すぎます（<枚数> 枚、上限 <上限> 枚）。コマ数か大きさを減らしてください` | GIF のコマ数またはポスターの大きさを小さくしてください。 |
| `動く画像の地図は現在 <枚数> 枚、上限 <上限> 枚です` | 自分の動く画像の地図数が上限です。不要な画像を運営に相談してください。 |
| `100 枚を超えています` | resize に指定した地図数が100枚を超えています。幅・高さを小さくしてください。 |
| `壁を直接右クリックしてください` | 地図を手に持って、額縁ではなく貼りたいブロックの面を右クリックしてください。 |
| `ここには貼れません（後ろのブロックが固体ではありません）` | 額縁の後ろに固体ブロックが必要です。 |
| `ここには貼れません（手前にブロックがあります）` / `ここには貼れません（額縁か絵画があります）` | ポスター全体の空間を空けてください。 |
| `ここは建築できません` | その場所に建築できません。運営または区域の管理者に確認してください。 |
| `管理している額縁が見つかりません` | 5ブロック以内の管理ポスター額縁を見て実行してください。 |
| `切り替える権限がありません` | 対象の額縁に他人のロックがあるか、ロックのない額縁の場所に建築できません。 |
| `外す権限がありません` | 対象の額縁に他人のロックがあるか、ロックのない額縁の場所に建築できません。運営または区域の管理者に確認してください。 |
| `画像の索引を読めません` / `額縁の記録を読めません: <理由>` | 画像または額縁の記録を読み込めませんでした。表示を運営に伝えてください。 |
| `この額縁はロックされています。` | 別の人がロックしています。額縁の持ち主に相談してください。 |
| `この額縁はすでにロックされています。` | ロック済みです。別のロックを追加する必要はありません。 |
| `この額縁はロックされていません。` | 解除対象にロックがありません。 |
| `この額縁は別のプレイヤーがロックしています。解除できません。` | ロックした本人だけが解除できます。 |
| `この額縁はロックされており破壊できません。` | ロックした本人または運営に相談してください。 |

額縁のコマンドが使えない場合、または表示が上記と異なる場合は、その表示を運営に伝えてください。
