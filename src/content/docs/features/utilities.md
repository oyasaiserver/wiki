移動、持ち物、採掘、飛行、ポーズなどの便利機能を使えます。使える機能や上限は利用資格によって変わります。下記に明記した条件以外は、機能とランクの対応が未確認です。利用できない場合は運営へ確認してください。

## バックパック

`/oyasaibackpack`（短縮形 `/obp`）で自分のバックパックを開き、アイテムを出し入れします。利用できるサイズは1〜6段です。

![](/images/seesaa/81e3865c870715d1.webp)

読み込み中や、既に開いている間は開き直せません。利用できる段数が減り、はみ出す位置に保存済みの物がある場合も開けません。運営へ相談してください。保存失敗の表示が出た場合は、再起動後も内容が残る保証がないため運営へ連絡してください。

## エレベーター

上下の同じX・Z座標に、次の組み合わせで床を作ります。**ジャンプで上へ、スニークで下へ**、最も近い同じ組み合わせの床へ移動します。

| 上のブロック | その直下 |
| --- | --- |
| クォーツブロック | レッドストーンブロック |
| 花崗岩 | 粗い土 |
| クォーツブロック | 白色の板ガラス |
| クォーツのハーフブロック | 鉄ブロック |
| 赤色のカーペット | 青色の羊毛 |

![](/images/seesaa/edXNCGHemt.webp)

移動先は40ブロック以内に作り、床の上に2ブロック分（赤色のカーペットは1ブロック分）の空間を空けてください。スペクテイターでは使えません。階数表示は周辺の探索範囲内で数えたものです。

## ホーム・ワープ・スポーンへ移動する

| やりたいこと | コマンド |
| --- | --- |
| 今いる安全な場所をホームにする | `/sethome 名前`（省略時は `home`） |
| ホームへ戻る | `/home 名前`（別名 `/homes`） |
| ホームを消す | `/delhome 名前`（別名 `/remhome`） |
| 自分のホームを全部消す | `/delhome *` |
| ワープ一覧を見る・移動する | `/warp`・`/warp 名前`（別名 `/warps`） |
| スポーンへ移動する | `/spawn` |

ホーム名は小文字として扱い、同名は上書きします。`bed`、整数だけの名前、`.` を含む名前は登録できません。1個だけ登録できる場合は、指定した名前に関係なく `home` に登録されます。

`/home` はホームが1個ならそこへ、複数なら一覧を表示します。存在しない名前を指定した場合も同じです。ホームが無いときは、設定によって復活地点かワールドのスポーンへ移動します。`/home bed` は有効なベッドなどの復活地点がある場合だけ使えます。

危険な移動先は周囲の安全な場所へ補正されることがあります。境界外や安全な場所が見つからない移動は断られます。クリエイティブ・スペクテイターではこの補正を受けません。

## プレイヤーへ移動する・申請する

| やりたいこと | コマンド |
| --- | --- |
| 相手へ直接移動する | `/tp 名前`（別名 `/tp2p`） |
| 相手を自分の場所へ呼ぶ | `/tphere 名前`（別名 `/s`） |
| 相手へ移動する許可を求める | `/tpa 名前`（別名 `/tpask`） |
| 自分の場所へ来てもらう許可を求める | `/tpahere 名前` |
| 届いた申請を承認・拒否する | `/tpaccept [名前]`・`/tpdeny [名前]`（別名 `/tpyes`・`/tpno`） |
| 自分が送った申請を取り消す | `/tpacancel [名前]` |

`/tp` はオンラインの完全な名前で指定してください。承認・拒否は名前を省略すると最新の1件、`*` または `all` で全件です。取消は省略すると自分が送った全件を処理します。

- 申請は通常120秒で切れます。通知に出る期限に従ってください。
- 同じ相手への申請が残っている間は再申請できません。自分への申請もできません。
- どちらかのログアウトや再起動で申請は消えます。
- `/tpahere` は申請した時点の自分の場所、`/tpa` は承認した時点の相手の場所へ移動します。
- 承認後も安全確認や移動制限で失敗することがあります。申請は移動開始前に消費されます。

### 受け入れを変える

`/tpset open` は原則受け入れ、`/tpset close` は原則拒否です。最初は open です。

| コマンド | 内容 |
| --- | --- |
| `/tpset ok 名前` | 許可リストへ追加し、拒否リストから外す |
| `/tpset ng 名前` | 拒否リストへ追加し、許可リストから外す |
| `/tpset none 名前` | 両方から外す |
| `/tpset mode` | open / close を確認 |
| `/tpset oklist`・`/tpset nglist` | 許可・拒否リストを見る |

open では拒否リストの人だけを断り、close では許可リストの人だけを受け入れます。運営からの移動など、すべての移動を禁止できるわけではありません。

### 移動履歴へ戻る・進む

`/back`(`/bk`)で前の地点へ、`/forward`（`/fow`・`/fw`）で次の地点へ戻れます。テレポートの出発地点と死亡地点が履歴になります。エレベーター・ポータル・エンダーパール・ジャンプなども対象です。新しい移動で「進む」の履歴は消えます。履歴はログアウト後も残りますが、再起動で失われます。

履歴の移動は安全な場所へ補正しません。取り消された移動も記録されることがあり、「TP中…」だけでは完了を判断できません。Pitaで慣性を止めた後は、次の移動が記録されない場合があります。入獄中はホーム・ワープ・スポーン・申請・履歴の移動を使えません。

## 作業台・持ち物を使う

| コマンド | 操作 |
| --- | --- |
| `/workbench`（`/craft`・`/wb`・`/c`） | 作業台を開く |
| `/enderchest`(`/ec`) | 自分のエンダーチェストを開く |
| `/disposal`（`/trash`・`/d`） | 36枠の廃棄メニューを開く |
| `/anvil`・`/loom`・`/grindstone` | 金床・機織り機・砥石を開く |
| `/stonecutter`・`/smithingtable` | 石切台・鍛冶台を開く |
| `/hat`(`/head`)・`/hat remove` | 主手のアイテムを頭にかぶる・外す |
| `/skull [名前]`（`/eskull`・`/playerskull`） | プレイヤーの頭を作る、または手の頭を変更 |

**廃棄メニューは閉じると入れた物を取り戻せません。** 帽子は主手のスタック全体と頭装備を交換します。耐久値のある物はかぶれず、束縛の呪いで交換・取り外しを断られる場合があります。外した帽子や生成した頭が入り切らない分は足元に落ちます。

頭の変更は主手が空なら副手の頭も対象です。取得中に手の物を変えると中止します。他人の頭の指定や生成が許可されていない場合は、自分の頭になるか、頭を持つよう案内されます。

## 採掘する

しゃがんで適切なツルハシで鉱石を掘ると、接している鉱石をまとめて掘れます。通常は最初の1個を含め最大64個です。斜めの接続や違う種類の鉱石も対象で、連鎖採掘後は待ち時間があります。クリエイティブでは発動せず、残り耐久が1以下になると追加採掘を止めます。

`/oresmelter toggle`(`/os toggle`)で自動精錬を切り替え、`/os status` で状態を確認します。ONならツルハシで掘った鉄・銅・金の原石がインゴットで落ちます。最初はOFFで、再起動でもOFFへ戻ります。

鉱石が再生成される指定ワールドでは、採掘後にいったん岩盤となり、時間がたつと元に戻ります。お金の報酬が有効なら、道具で計算したドロップ数と鉱石ごとの単価で入金されます。対象外のブロックの破壊やブロックの設置は制限されます。

## 飛行・状態・表示を変える

| コマンド | 内容 |
| --- | --- |
| `/fly [on または off]` | 飛行許可を切替（省略時は反転） |
| `/speed 数値`・`/speed fly 数値`・`/speed walk 数値` | 飛行・歩行速度を変更。種別省略時は飛行中なら飛行速度 |
| `/flyspeed 数値` | 飛行速度を指定 |
| `/sokudo 数値` | 0.1〜5で飛行速度を指定。1が通常速度 |
| `/pita` | 飛行中に入力を離したときの慣性停止を切替 |
| `/jump`（`/j`・`/jumpto`） | 最大300ブロック先の照準にある安全なブロックの上へ移動 |
| `/jump lock` | 飛行中の空中左クリックによるジャンプを切替 |
| `/afk [メッセージ]` | 離席・復帰を切替 |
| `/heal` | 体力・食料・空気を回復し、火を消す。通常は効果も消える |
| `/anshi` | 暗視を切替 |
| `/nick 名前`・`/nick off` | ニックネームを設定・解除 |
| `/realname ニックネームの一部` | オンラインで見える人の実名を調べる |
| `/ptime day`・`/ptime @midnight`・`/ptime reset` | 自分に見える時刻を相対指定・固定指定・通常へ戻す（別名 `/playertime`） |
| `/reach 数値`・`/reach reset` | 操作距離を変更・標準へ戻す |
| `/scale 数値` | 体の大きさを変更 |
| `/getdebugstick` | クリエイティブのときデバッグ棒を受け取る |
| `/l` | プレイヤー一覧を表示 |

`/speed` は1が通常速度で、入力は0.0001〜10へ補正されます。1より大きい値は許可された上限までの段階で、`/sokudo` と同じ倍率ではありません。Pitaが全体で有効なら、OFF表示でも慣性停止は続きます。

回復は通常60秒の待ち時間があり、失敗でも待ち時間が付く場合があります。ニックネームは通常32文字まで（色指定も含む）、英数字と `_` が使えます。重複名や禁止名は使えません。時刻を数値指定するなら `/ptime 100ticks` のように単位を付けてください。

離席は操作・チャットや開始地点から3ブロックを超える移動などで解除します。視点変更だけでは解除しません。自動離席を使える人は通常600秒の無操作で離席します。

reachの上限は利用資格に応じて16・32・48・64です。scaleは−16〜16、1または省略で通常、2で2倍、−4で1/4倍です。対戦用の指定ワールドでは使えず、そのワールドへの移動やログアウトで標準へ戻ります。

### Red Bullで24時間飛ぶ

`/redbull` またはRed Bullアイテムを飲むと、飛行資格が無い人は20ポイントで24時間飛べます。上級ランクの人、既に一日券が有効な人、常設の飛行資格がある人は無料で飛行を有効にし、アイテムも消費しません。**再使用で期限は延びません。**

アイテムは通常の右クリックで飲み、しゃがみ右クリックなら頭ブロックとして置けます。期限表示は日本時間です。再ログインでも期限を引き継ぎ、期限切れで飛行が止まる場合があります。

## スキンを変える・UUIDを調べる

`/skin set MinecraftID` でスキンを変更し、`/skin reset` で本来のスキンへ戻します。再ログインにも引き継ぎます。IDは英数字と `_` の3〜16文字です。取得中は少し待ってください。統合版では使えません。

`/uuid 名前` は参加したことのある人のUUIDを2形式で表示します。表示をクリックしてコピーできます。未参加の人は取得できません。

## 座る・ポーズを取る

| コマンド | ポーズ |
| --- | --- |
| `/sit`(`/gsit`) | 座る |
| `/lay`（`/glay`・`/layback`・`/glayback`） | 仰向け |
| `/bellyflop`(`/gbellyflop`) | うつ伏せ |
| `/spin`(`/gspin`) | 回転 |
| `/crawl`(`/gcrawl`) | 這う |

同じコマンドをもう一度使うかスニークで解除します。地面にいて、飛行・滑空・水中・乗り物・睡眠・スペクテイターではないときに始められます。退出・死亡・テレポート・ゲームモード変更などでも解除されます。

主手が空なら通常向きの階段、下付きハーフ、カーペット・苔のカーペット、薄い雪への右クリックでも座れます。上に空間が必要で、しゃがみ中は発動しません。`/sit toggle` でこの操作だけをON/OFFにできます。

主手が空なら他のプレイヤーへの右クリックで、相手や積み重なった人の最上段に乗れる場合があります。通常は自分より指定順で下の階級の人だけが対象です。乗られる側が拒否する個人設定はありません。`/sit toggle` ではこの操作を止められません。

## パーティクルを装備する

`/h`(`/particlehats`)でメニューを開き、装備したい物をクリックします。同じ物をクリックすると外れます。通常は同時7個までで、装備できる種類は利用資格によって変わります。

Thief!は走行中、Rocket Trailは滑空中、Tornadoは飛行中だけ表示されます。透明化中・死亡中や「この種類は表示しません」とある種類では表示を止めます。

## ブロックの表示を一時的に変える

`/togo [半径] [秒数]`（`/refreshtogo`・`/-`）で周辺ブロックの表示を一時的に変えます。通常は半径10・60秒・最大35個です。もう一度 `/togo` で解除します。`/togom` で種類・個数・半径・時間を選び、`/togom reset` で初期化できます。

階段・壁・フェンス・ハーフ・ドア・トラップドア・板ガラス・鉄格子のうち、表示が用意されたものが対象です。実際の素材は変わりませんが、表示中の対象の破壊は止まります。

`/togo auto` でデバッグ棒を持ったときの自動起動を切り替えます。`/togom` で受け取る自動起動アイテムも使えます。主手・副手から外すと解除します。表示位置は移動に追従せず、時間切れでも持ち続けるだけでは再起動しません。

## 案内を受ける・案内する

案内者に登録してもらい、表面1行目が `[案内完了]` の看板を右クリックします。エリアごとに一度だけ完了でき、案内者には10トークンの報酬があります。

案内者は**上級ランクから**利用できます。`/annaimode 名前` で初心者を登録し、`/annaimode` で解除します。既に案内中なら解除してから登録し直してください。`/guidecheck 名前` でオンラインの人の最後の案内者・完了日時を確認できます。`/annai`・`/annai-en` は案内文メニューを開きます。

## タイマーを見る

タイマーが開始されると画面上部に残り時間が表示され、途中から参加した人にも見えます。0秒になっても終了操作まで `END!` が残ります。

## ゲームモードとアイテムの注意

利用が許可された人は `/gamemode モード`(`/gm`)や `/gmc`(`/creative`)、`/gms`(`/survival`)、`/gmsp`（`/sp`・`/spec`・`/spectator`）、`/gma` で切り替えられます。

通常は各モードで持ち物を別に保存します。初めて使うモードの持ち物は空です。変更時に効果が消える場合もあります。

クリエイティブで置いたブロックからは物が落ちません。通常はクリエイティブ由来の落とした物をサバイバルで拾えず、逆も同様です。容器や防具立てでも異なるモード由来の物の操作が止まる場合があります。保存済みホットバーなどの付加情報の除去や、頭の複製制限もあります。アドベンチャー・スペクテイターでは通常の容器の持ち物操作も制限されます。クリエイティブのスポーンエッグ使用は制限されます。

## おえかきマップ

地図を額縁に飾り、染料で絵を描けます(PaintTools)。使えるランクは未確認です。利用できない場合は運営へ確認してください。

1. 持ち物に空きを作り、`/painttools canvas` でキャンバス地図を受け取って額縁に飾ります。入り切らなかった地図は返されません。
2. `/painttools dye` で染料一覧を開き、道具を手に持ちます。
3. 額縁の地図に向けて描きます。

| 操作・道具 | 内容 |
| --- | --- |
| 染料で右クリック | ブラシで描く（初期サイズ2） |
| 左クリック | つながった同じ色の範囲を塗り替える |
| しゃがんで左クリック | 離れた部分も含め同じ色を置換（染料・紙・羽根・イカスミ・砂糖） |
| 染料でしゃがみ右クリック | キャンバス全体を塗る |
| 紙・羽根・イカスミ・砂糖 | 消しゴム・色指定ペン・暗くする・明るくする |
| `/painttools brushsize 0`〜`20` | ブラシサイズを変更 |
| `/painttools undo [1〜3]` | 約1〜3分前の記録へ戻す |

染料一覧の羽根を持って空中かブロックを左クリックすると色入力画面を開きます。`255,255,255` または `#FFFFFF` で入力します。`1,1,1`・`#010101` は透明色です。染料アイテムはクラフトには使えません。起動用アイテムが登録されていれば `/getdye` で受け取れ、初回参加時にも配布されます。

Undoは額縁から8ブロック以内で実行してください。3回分の記録がそろうまでは1段階も使えず、表示も出ません。記録開始から通常約130秒が必要で、記録時に読み込まれていなかったキャンバスも戻せません。

画像の地図や額縁のロック・透明化は、[画像を地図にして飾る](/features/frames/)をご覧ください。

## 困ったとき

権限不足の表示は利用資格、移動できない表示は移動先の安全や読み込みを確認してください。バックパックの読み込み・保存失敗は、その表示を運営へ伝えてください。おえかきで「キャンバスを読み込み中です」と出たら少し待って描き直します。
