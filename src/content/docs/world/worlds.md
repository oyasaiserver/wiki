## ロビー（ゲートエリア）

おやさい鯖に入ったとき始めて来る場所です。

#### 特徴

* 〈/spawn〉コマンドでいつでも帰ってこれる。
* 食料配布所がある。
* 様々な場所へ行けるゲートがある。
* 歴代の匠像がある。
* 爆発・延焼・モブ無効で安心安全。

![](/images/seesaa/ezJLhPic9n.webp)

### 注意事項

* ゲートにある看板はよく読みましょう！建築可能な場所、不可な所があります。
* ここでの建築は基本禁止です。
* 破壊行為はもちろんNGです。壊してしまったら自分の手で直しましょう！

## メインワールド（メインネザー）

建築をしたり生活を送ったりする所です。

#### 特徴

* おやさい鯖の醍醐味、建築をすることができる。
* 爆発・延焼・モブ無効で安心、安全！
* 保護をしたり、チェストやかまどにロックを掛け、自分のアイテムを保管できる。
* 畑や釣り場などを作って、ゆったりとしたマイクラライフを送ることもできる。
* 色んな人が建てた様々な建築物を眺められる。

![](/images/seesaa/FBf6Nqjkv4.webp)  
【作：umetaro323　題：草。教会】

### 注意事項

* 採掘行為は基本的に禁止です(地形も重要な建築要素になりえるため)。
* 上に関連して、巨大建築等どうしても必要な場合以外の整地は控えてください。
* 保護がかかっていない建築物でも、その権利は制作者にあります。破壊はもちろん処罰対象ですが、無断で改変等した場合、制作者の意向によってはロールバック処理されますのでご理解ください。
* 著しく景観を乱す建築は撤去または移転される場合があります(**涅槃先輩像は問題ありません**)。
* 植物系の成長は止めてあります。成長させる場合おやさい中央市場でデバック棒を購入し、使用してください。

## エンドワールド

ごく普通のエンドワールド

#### 特徴

* エンド特有の雰囲気を活かした建築ができる。
* エンダーマンのトラップタワーがある。
* 爆発・延焼無効で安心！
* エンダーマン以外は湧きません。
* エンドシティ・エンドシップはありません。

![](/images/seesaa/J_LVr3Havl.webp)

### 注意事項

* 基本的にメインワールドと一緒です。

## 資源ワールド（資源ネザー）

資源採掘OKなワールドです。

#### 特徴

* ワールドに入ってすぐ目の前に鉱山ワールドの入口がある。
* 鉱石一括採掘機能が有効で、掘る時間も短縮されている。
* 鉱山ワールドがあるのでわざわざ地下深くまで掘る必要がなく、建築により多くの時間を割ける。

![](/images/seesaa/OSyb0Juq5u.webp)

### 注意事項

* ここに建築をしてもランクへの反映がないうえ、資源更新時に建築物は抹消されます。
* 保護系は無効です。アイテムはメインワールドにて保管してください。
* ラピスラズリ鉱石を幸運のピッケルで採掘した場合、処理軽減のためにドロップアイテムが消滅させられる場合があります。

## ワールド間の移動とポータル（OyasaiWorldGenerator）

おやさいサーバーでは、展示用のボイドワールドやスーパーフラットワールドなど、用途に応じたさまざまなワールドが管理されています。
ワールド間の移動には、コマンドや設置された専用ポータルを利用します。

### 移動コマンド

| コマンド | 説明 |
|---|---|
| `/owg tp [ワールド名]` | 高さを管理するワールド（ボイド・フラット等）へ移動します。移動成功時にそのワールド専用のゲームモードと飛行設定が適用されます。 |
| `/mvtp <ワールド名>` | 通常ワールドや高さを管理するワールドへ移動します。高さを管理するワールドへの移動時は専用のゲームモード・飛行設定が適用されます（通常ワールドへの移動時は切り替わりません）。 |

- コマンドの利用にはサーバー側の権限が必要です。
- コマンドではなくポータルなど他の移動手段で入った場合、そのワールド用のゲームモードや飛行設定は自動で適用されません。
- ボイドワールドでは足場が生成されない場所もあるため、安全な到着地点を確認してください。また、ワールドから退出しても入場前のゲームモードや飛行状態へ自動で戻らない点にご注意ください。

### ポータルの利用

ワールド内に設置されている専用ポータルの範囲内に歩いて入ると、設定された移動先へテレポートします。

- **乗り物での利用**: 馬や車両などの乗り物に乗ったままポータルに入ると、プレイヤーのみが移動先にテレポートし、乗り物は元の場所に残されます。
- **再発動**: ポータルに到着した直後はその場で再発動しません。一度ポータルの範囲外に出てから入り直してください（徒歩・乗り物ともに再利用には1秒の間隔が必要です）。
- ポータルに入っても反応しない場合は、移動先のワールドが準備中であるか一時的な不具合の可能性があるため、運営へお知らせください。

### 困ったとき・エラーメッセージ

| 表示 | 意味・対応 |
|---|---|
| `[OWG] 対象ワールドが見つかりません` | 指定したワールドが存在しないか移動対象外です。ワールド名を確認してください。 |
| `[OWG] まだ準備できていません` | 対象のワールドがまだ読み込まれていません。時間をおいて再度お試しください。 |
| `[OWG] 移動に失敗しました` / `[MV] 移動に失敗しました` | サーバー側での移動処理に失敗しました。続く場合は運営へご連絡ください。 |
| `[MV] 読み込み済みワールドが見つかりません: <ワールド名>` | 指定したワールドが見つからないか、ロードされていません。 |
