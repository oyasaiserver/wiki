チャット欄に `/menu`（短縮形 `/mn`）と入力すると、おやさいサーバーの総合メニュー画面を開くことができます。
また、メニューアイテム（メニュー本）を手に持って右クリックすることでも開けます。

![](/images/seesaa/U5bpcaZ6P4.webp)

## メニューの開き方

- **コマンド**: `/menu` または `/mn`
- **メニューアイテム**: 初回ログイン時に渡されるほか、`/getmenu` で受け取ることができます。メインハンドに持って右クリックするとメニューが開きます。
  - 名前などを変更すると開けなくなる場合があります。
  - メニューアイテムをクラフトの材料に使うことはできません。
- **メインメニューの項目**: チャンネル、売却、ショップ、SocialLikes、CarBuilder、ユーティリティ、リンク集が並んでいます。
- **プロフィール**: メニュー下部の中央にあるアイコンを押すと、自分の所持金やトークン（ポイント）を確認できます。
- **ナビゲーション**: サブメニュー画面で、下部にある現在開いているメニューのアイコンをもう一度押すとメインメニューに戻ります。

## メニュー各項目の説明

### チャット切り替え

![](/images/seesaa/a5Sep3xmCY.webp)

参加するチャットルームの切り替えや、現在の各チャンネルの接続人数を確認できます。

### サーバーショップ（`/shop`）

建材や装飾ブロックなどを購入したり、採掘した鉱石を売却したりできます。
コマンド `/shop`（短縮形 `/sh`）から直接開くことも可能です。

![](/images/seesaa/uqHL37AAhz.webp)

- **カテゴリ直接指定**:
  - `/shop blocks`（短縮 `/shop bl`）: 建材ショップ
  - `/shop decorations`（短縮 `/shop deco`）: 装飾ショップ
  - `/shop ores`（短縮 `/shop ore`）: 鉱石ショップ
  - `/shop tools`（短縮 `/shop tool`）: ツールショップ
  - `/shop ps`（または `/pointshop`・`/ps`）: ポイントショップ

#### ショップ画面の操作方法

![](/images/seesaa/zC420g5fY_.webp)

- **購入と売却**:
  - 通常は **左クリックで購入**、**右クリックで売却** します。
  - 画面内の「左右反転ボタン」を押すと、左クリックと右クリックの動作（購入・売却）が入れ替わります。
- **取引数量の変更**:
  - 画面内の数量ボタンを押すことで、一度に取引する数量を **1個・4個・16個・64個** から切り替えられます。
- **一括操作（Shiftクリック）**:
  - 通常設定時は、**Shift+左クリックで64個購入**、**Shift+右クリックで手持ちの該当アイテムを全売却** します（左右反転時はこの操作も入れ替わります）。
- **売却の条件**:
  - アイテムを売るには、素材だけでなく通常エンチャントの種類・レベルがショップの商品と完全に一致している必要があります。
  - 買取価格が設定されていないアイテムや、在庫にないアイテムは売却できません。
  - クリエイティブモードでは通常ショップでの売買は利用できません。サバイバルモードに切り替えてご利用ください。

#### ポイントショップ（`/pointshop` / `/ps`）

投票ポイント（トークン）を使って、エリトラや限定アイテム、各種権限を購入できます。
商品は左クリックで購入します。

### アイテムの一括売却（`/sell`）

不要なアイテムや採掘した鉱石をまとめて売却できる便利な機能です。

- **`/sell`**: 売却画面（GUI）を開きます。上段の枠に売りたいアイテムを入れて「売却実行」を押すとまとめて売却されます。売れないアイテムは画面に残り、画面を閉じると手元に戻ります。
- **`/sell hand`**: 手に持っているアイテムをその場で売却します。
- **`/sell all`**: インベントリ内にある売却可能なアイテムをまとめて売却します。

> [!WARNING]
> 大切なアイテムは売却前に必ず取り分けてチェスト等へ保管してください。
> 中身が入ったシュルカーボックスであっても売却条件を満たすと売却されてしまい、**中身ごと失われる危険があります**。
> なお、クリエイティブモードでは売却機能は使用できません。

### ユーザーコマンド・ユーティリティ

スポーン地点へのテレポート、作業台、エンダーチェスト、バックパック、ゲームモード変更などのショートカットが用意されています。

![](/images/seesaa/8jTI7e7dZv.webp)
![](/images/seesaa/q3GFdcl2cn.webp)

- **作業台**: どこでも作業台画面を開きます（`/c`）。
- **エンダーチェスト**: どこでもエンダーチェストを開きます（`/ec`）。
- **バックパック**: インベントリを拡張するバックパックを開きます（`/bp`）。
- **スポーン地点**: ロビーへ戻ります（`/spawn`）。
- **バック**: 直前のテレポート元や死亡地点に戻ります（`/back`、上級ランク以上）。
- **飛行（フライ）**: 飛行モードを切り替えます（`/fly`、上級ランク以上またはポイント購入者）。
- ※ユーティリティ内の「Language」ボタンは現在準備中のため、押しても何も起きません。

### SocialLikes

建築物を登録して「イイネ」を受け取ったり、他の人の建築を検索・訪問できる機能です。
詳しくは [SocialLikes](/features/sociallikes/) をご覧ください。

![](/images/seesaa/F0L46F_xX5.webp)

### CarBuilder & 乗り物

車両の購入・カスタマイズ・スポーンを行えます。
詳しくは [乗り物](/features/vehicles/) をご覧ください。

![](/images/seesaa/OyhzjZjgLB.webp)

### 各種リンク

公式DiscordやWebMap、投票サイトなどへのリンクが集約されています。クリックするとチャット欄にURLが表示されます。

![](/images/seesaa/Qq34OhiHXl.webp)

## 困ったとき・エラーメッセージ

| 表示 | 意味・対応 |
|---|---|
| `You can not use the menu item in crafting!` | メニューアイテム（本）を作業台などのクラフト材料に使うことはできません。 |
| `残高不足 (所持: ... / 必要: ...)` | 商品の購入に必要なお金（円）が足りません。 |
| `ポイントが不足しています。(所持: ... / 必要: ...)` | ポイントショップの購入に必要なポイントが足りません。 |
| `クリエイティブモードではショップを使用できません。` / `クリエイティブモードでは売却できません。` | サバイバルモードなど通常モードに切り替えてからご利用ください。 |
| `売却可能なアイテムがありませんでした。` | 売却対象のアイテムが登録されていないか、買い取りに対応していません。 |
| `もう少し待ってから実行してください。` | コマンドを連続で実行しています。少し時間をおいてから再試行してください。 |
