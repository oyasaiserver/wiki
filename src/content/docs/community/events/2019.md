## 公式・クリスマスイベント 2019年12月11日 10:00 〜 2019年12月26日 21:00

おやさい鯖クリスマス建築大会  
〜すっげぇ白くなってる(積雪)はっきりわかんだね〜  
期間：2019年12月11日 10:00 〜 2019年12月26日 21:00  
場所：自由  
内容：冬(クリスマスは体裁)にちなんだ建築をする。  
参加方法：建築物の応募はDiscordの #応募 チャンネルにSocialLikes(いいね看板)のID番号を書き込む。  
審査：投票フォームからの投票。  
賞品  
景品一覧  
優勝者 : エリトラ(ダメージ軽減IV + 不可壊)  
2位 : 200万ダボ+トライデント(忠誠+召雷)  
3位 : エリトラ+トライデント  
4位 : 100万ダボ  
参加賞 : クリスマストーチ(火属性+ノックバックIVの松明)

## 個人・ハロウィンイベント 2019年10月31日 〜 2019年11月3日

ハロウィンイベント 建築大会  
期間：2019年10月31日 19:00 〜 2019年11月3日 20:00  
場所：ケイン地区の外れ(ゲートエリアからワープが可能)  
主催：maikukosyou  
内容：ハロウィンにちなんだ建築をする。かぼちゃを必ず使わなければならないとかいう~~めんどくさい~~規定はない。  
参加方法：イベント会場の道路沿いに建築物を作り、イベント会場本部**↓**の応募欄に建築物の名前、座標、自分の名前を書いて応募する。

審査：Like看板を利用した投票で順位を決定する。  
賞品  
1位：500万ダ + ぶっ飛び棒ハロウィン限定版  
2位：300万ダ  
3位：50万ダ  
4位以降：ダイヤモンド1スタック(64個)

## 公式・1000円だけの逆ブルジョワ建築大会 2019年11月06日 〜 2019年11月13日

「第1回チキチキ！1000円だけの逆ブルジョワ建築大会〜！！」

※当時、多くの建材が1ブロック1ダボだった。  
アイディアはhirasyo兄貴から。ありがとナス！  
タイトルの通り、1000ダボ以内で建築しましょうって企画です。

建てる場所はどこでも構いません。建築物の応募は #応募 チャンネルに  
SocialLikesのID番号を書き込んでください  
やり方はこちらです <http://wiki.baakun.com/d/SocialLikes>

景品一覧  
優勝者 : 500万ダボ+効率10ダイヤピッケル  
2位 : 300万ダボ+エリトラ  
3位 : 100万ダボ  
4位 : エリトラ  
5位以降 : ダイヤ1スタック

今回から優勝者にはDiscordの役職がつけられます。「第○回△△大会優勝者」って感じの役職です。  
ふるってごさんかください。
