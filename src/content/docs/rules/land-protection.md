おやさいサーバーでは、自分の建築物を守る「**土地の保護**」（WorldGuard）と、チェストやドアを他の人に触られないようにする「**チェスト等の施錠・保護**」（OyasaiLWC）を利用できます。

## 土地の保護（WorldGuard）

木の斧を使って指定した範囲の土地を保護できます。保護された土地では、メンバー以外のプレイヤーによるブロックの設置や破壊を防ぐことができます。

### 土地の保護の手順

![](https://image02.seesaawiki.jp/o/i/oyasai/sWlgz0obf9.29.50.png)

1. **木の斧**を用意します。
2. 保護したい領域の対角線となる2つの角を指定します。
   - 最初の角を **左クリック** します。
   - 反対側の対角線となる角を **右クリック** します。

![](https://image01.seesaawiki.jp/o/i/oyasai/J4IA5RbEe7.18.36.png)
![](https://image01.seesaawiki.jp/o/i/oyasai/W_1gaDGp1B.55.32.png)

3. チャット欄に `/region claim <土地の名前>` と入力すると、土地の保護が完了します。

### 土地保護のコマンド一覧

| コマンド | 説明 |
|---|---|
| `/region claim <土地の名前>` | 木の斧で指定した範囲を保護します |
| `/region remove <土地の名前>` | 保護している土地を削除します |
| `/region list` | 自分が保護している土地の一覧を表示します |
| `/region addmember <土地の名前> <プレイヤー名>` | 保護領域に共同建築メンバーを追加します |
| `/region removemember <土地の名前> <プレイヤー名>` | 保護領域のメンバーから削除します |
| `/region info` | 現在立っている保護領域の情報を確認します |

## チェスト・ドア等の施錠（OyasaiLWC）

チェストや樽、ドアなどに鍵をかけて、自分と共有した人だけが使えるようにする機能です。
**ブロックを置いただけでは鍵はかかりません。** 必ずコマンドで施錠してください。

### 基本の操作方法

コマンドを入力してから **30秒以内に対象のブロックを右クリック** します。
右クリックした時点でコマンドが完了します。違うブロックをクリックした場合は、もう一度コマンドを入力してください。

### 鍵をかける（`/lock`）

チャット欄に `/lock`（別名 `/cprivate`）と入力し、対象ブロックを右クリックします。「ブロックを保護しました」と表示されれば完了です。

#### まとめて鍵をかける（自動保護モード）

大量のチェストを並べるときは、`/lock auto` が便利です。

- モード中に設置した**容器**に自動で鍵がかかります。
- モードの制限時間は60秒です。容器を置くたびに残り時間が60秒にリセットされます（ドアなど容器以外ではリセットされません）。
- 別のワールドへ移動すると終了します。もう一度 `/lock auto` を打つと途中で終了できます。
- 鍵付きチェストの隣に置いてラージチェストにした場合は、新しい鍵は作られず元の鍵の設定（持ち主・共有・ホッパー）が引き継がれます。

### 鍵をかけられるブロック

- **容器**: チェスト、トラップチェスト、銅のチェスト、樽、シュルカーボックス、かまど、溶鉱炉、燻製器、ディスペンサー、ドロッパー、コンポスター、書見台、飾り壺、クラフター、シェルフ
- **その他**: ドア、トラップドア、フェンスゲート、看板、旗

> [!NOTE]
> ラージチェストや観音開きのドアは、片方に鍵をかければ両方が保護されます。
> ただしラージチェストの鍵は**最初にクリックした側**に記録されるため、そちら側を壊すと残った側の鍵も外れます。

### 見せるだけの鍵（展示用 `/cdisplay`）

`/cdisplay` を入力してブロックを右クリックすると、展示用の鍵がかかります。

- チェストなどを開いて中身を見ることはできますが、**誰もアイテムを出し入れできません**（持ち主・共有相手も含む）。
- 看板、ドア、トラップドアなどは右クリックそのものができなくなります。
- 書見台の本は読むことができますが、持ち去ることはできません。
- 中身を入れ替えたい場合は、一度 `/unlock` で外してから中身を入れ替え、再度 `/cdisplay` をかけてください。

### 友だちと共有する（`/cmodify`）

保護したブロックを友だちと一緒に使いたい場合は、`/cmodify` を使用します。

1. `/cmodify <プレイヤー名>` を入力します（例: `/cmodify Alice Bob` のように複数人同時に指定可能）。
2. 対象のブロックを右クリックします。
3. 共有を解除したい場合は、名前の前に `-` を付けます（例: `/cmodify -Alice`）。

※共有された人は中身の出し入れや開閉ができますが、鍵の解除・設定変更・ブロックの破壊は持ち主と管理者しかできません。
※他人の保護チェストの隣（前後左右）に同じ種類・向きのチェストを置くことはできません。

### ホッパーを使えるようにする（`/chopper`）

鍵をかけた容器は、標準でホッパーやホッパー付きトロッコによるアイテムの吸い出し・搬入が遮断されます。
自動仕分け機や搬送回路に組み込む場合は、以下の操作を行ってください。

- `/chopper on` を入力してブロックを右クリックします（戻すときは `/chopper off`）。
- **移動元と移動先の両方**に鍵がかかっている場合は、両方のブロックで `/chopper on` に設定する必要があります。

### 鍵の確認・解除

| やりたいこと | コマンド（実行後に対象を右クリック） |
|---|---|
| 持ち主・種類・共有相手・ホッパー設定を確認する | `/cinfo` |
| 鍵を外す（保護解除） | `/unlock`（別名 `/cremove`） |

### 困ったとき・エラーメッセージ

| 表示 | 意味・対応 |
|---|---|
| `このブロックは保護されています` | 他のプレイヤーが施錠しています。持ち主に共有を依頼してください。 |
| `すでに保護されています` | 既に鍵がかかっています。種類を変えたい場合は一度 `/unlock` で外してください。 |
| `このブロックは保護できません` | 保護に対応していないブロックです。 |
| `他人の保護チェストの隣には置けません` | 他人のチェストと繋がるのを防ぐための制限です。少し位置を離すか、しゃがみながら置いてください。 |
| `持ち主か管理者だけが変更できます / 壊せます` | 鍵の変更や解除、ブロックの破壊は持ち主本人のみ可能です。 |
| `操作の有効時間が切れました（30 秒経過）` | コマンド実行から30秒以上経過しました。もう一度コマンドを入力してください。 |
| `このコマンドは廃止しました` | `/cpublic`・`/cpassword`・`/cunlock` などの古いコマンドは廃止されました。`/lock` や `/unlock` をご利用ください。 |
