おやさい鯖では、建築の合間に楽しめるよう、さまざまなミニゲームが用意されています。

ミニゲームの多くは `/games`（別名 `/og`・`/oyasaigames`）で開く統合メニューからアクセスできます。

## ミニゲームメニュー

チャット欄に `/games` と入力すると、ミニゲーム用のメニュー画面が開きます。
メニューから建築アイテムルーレット、サイコロ、HeadHuntの案内、BedWarsの参加画面などを直接開くことができます。

## 建築アイテムルーレット

建築に使うブロックのアイデアを出したいときに役立つルーレット機能です。

1. `/roulette`（別名 `/oroulette`）を実行するか、`/games` メニューから開きます。
2. 対象ブロック（「全建築用アイテム」「フルブロックのみ」「フルブロック以外」）を選びます。
3. 抽選回数（1・3・5回）と、結果を全体に知らせるか自分だけにするか（全体公開 / 自分のみ）を選びます（初期選択は全建築用アイテム・1回・全体公開です）。
4. 右下のトーチ「▶ ルーレットを回す！」を押します。

結果のブロックはチャットと画面に表示されます。チャットのブロック名をクリックするとブロックIDをコピーできます。
※ブロック自体を入手する機能ではなく、抽選候補を提案する機能です。同じブロックが複数回選ばれることもあります。

- 画面を閉じても抽選は継続します。ログアウトすると進行中の抽選は停止します。
- 抽選中は次の抽選を開始できません。完了後は通常10秒の待ち時間があります。
- 特殊ブロックがロック中と表示される場合、そのブロックは候補に入りません（赤匠ランクで解放されます）。

## おやさいサイコロ

チャット欄に `/dice`（別名 `/saikoro`・`/odice`）と入力すると、サイコロを入手できます。

- 種類を指定する場合は `/dice get 2d6` のように入力します。
- 使用できる面数は **D2・D4・D6・D8・D10・D12・D20・D100**、個数は **1〜10個** です。対応していない面数は D6 に置き換わります（例: `3d7` → 3D6）。形式を読み取れない指定は 1D6 になります。
- すでにサイコロを持っている状態で `/dice` や `/dice get` を実行すると、手持ちのサイコロのモードが変更されます。

### 振り方と回収

1. サイコロをメインの手に持ち、**右クリックを長押し**して投げる強さをためます。
2. 右クリックを離すか、最大までためると投げます。止まると出目がチャットに表示され、複数個の場合は合計値も表示されます。
3. 投げたサイコロの近くで**右クリック**して回収します。サイコロが止まってから15秒で自動回収され、投げ始めから25秒でも回収処理が行われます。

しゃがみながら右クリックすると、種類・個数・通知の公開/非公開を設定できます。

- 1人が持てるサイコロは1個です。投げたサイコロが戻るまでは新しいサイコロを入手できません。
- 投げた直後の2秒間は再投擲できません。
- 公開通知は同じワールドの周囲30ブロック以内に届きます。非公開に設定すると、チャット通知は本人のみに限定されます。
- 他のプレイヤーのサイコロは回収できません。

## HeadHunt（頭ブロックの宝探し）

運営がイベントを開始した際に遊べる、会場内に隠された頭ブロック（宝HEAD）を探すゲームです。

- `/headhunt`（別名 `/hhunt`）: 案内を表示します。
- `/headhunt team list`: チーム一覧を表示します。
- `/headhunt team info [チーム名]`: 自分または指定チームの情報を表示します。

会場に設置された宝HEADを、メインの手で右クリックして探します。

| 方式 | 勝利条件 |
|---|---|
| 個人戦 | 1人ですべての宝を見つける（事前登録不要で誰でも参加可能） |
| チーム戦・共有 | チームで全ての宝を見つける（誰かが見つけた宝はチーム内で共有される） |
| チーム戦・個人発見 | 開始時のチームメンバー全員が、それぞれ全ての宝を見つける |

- 最初に勝利条件を満たした人またはチームが出るとイベントは終了します。
- 宝HEADは通常のブロックのように破壊することはできません。

## PvP（アリーナ対戦）

さまざまなルールで対戦できるPvPアリーナです。
ロビーのゲート、またはコマンドでアクセスできます。

1. `/pa list`（別名 `/pvparena`・`/ogpa`）で使用可能なアリーナ一覧を確認します。
2. `/pa アリーナ名 [チーム名]` で参加します。チーム名を省略すると人数の少ないチームへ自動で割り振られます。
3. クラス選択が必要なアリーナでは `/pa class クラス名`、準備完了は `/pa ready` を使用します（看板やブロックから選択できる場合もあります）。
4. 退出しようとする場合は `/pa leave` を使用します。
5. `/pa stats` で累積キル数・死亡数・勝利数を確認できます。

- アリーナごとに勝敗条件、参加人数、途中参加の可否、参加費や報酬が異なります。
- 観戦する場合は `/pa アリーナ名 spectate` を使用します。
- 参加・観戦中はコマンドや持ち物の操作が制限され、退出時に参加前の持ち物と状態へ復元されます。カーソルにアイテムを持った状態で参加しないでください。
- 賭けが有効なアリーナでは、試合に出ていないプレイヤーが `/pa アリーナ名 bet 対象 金額` で勝敗を予想して賭けることができます。引き分け時は返金され、外れた場合は払戻しがありません。

### 主なアリーナ紹介

- **BasicArena**: 短時間で終わるバニラ装備のシンプルなPvPアリーナです。
- **l1l1Arena**: 大人数向けのシンプルなPvPアリーナです。
- **SiroArena**: 巨大な城の周囲を飛び回りながら対決するアリーナです。
- **BowPvP**: 弓のみを使用して戦うシンプルなPvPアリーナです。
- **oyasaichampions**: 10回倒されないように競い合うFPS風アリーナです。

## BedWars（ベッドウォーズ）

拠点のベッドを守りながら、相手チームのベッドを破壊して最後まで生き残るチーム対戦ゲームです。

`/bw gui`（別名 `/bedwars`）または `/games` メニューから参加画面を開けます。
`/bw list` で会場一覧を確認し、`/bw join アリーナ名` または会場の参加看板から参加できます。

- **ルール**:
  - 自チームのベッドが残っていれば、倒されても何度でも復活できます。
  - ベッドが破壊された後に倒されると復活できず、観戦モードになります。最後まで生き残ったチームが勝利します。
- **ショップと強化**:
  - 拠点や中央の島に湧く鉄・金・ダイヤモンド・エメラルドを集め、ショップNPCを右クリックするか `/bw shop`・`/bw upgrades` でアイテム購入やチーム強化を行います。
- **退出と復帰**:
  - 試合から抜ける場合は `/bw leave` を実行します。
  - 回線切断や誤って退出した場合、試合が続いており自チームのベッドが残っていれば `/bw rejoin` で試合に復帰できます（試合中の持ち物は引き継がれません）。
- **統計**:
  - `/bw stats` で自分の戦績、`/bw leaderboard` で上位10人のランキングを確認できます。
- **パーティー**:
  - `/bwparty invite 名前` でパーティーに招待し、招待された側は `/bwparty accept リーダー名` で参加します（別名 `/party`）。
- **チャット**:
  - 試合中のチャットは通常チーム内にのみ届きます。先頭に `@a` を付けるか、`/shout メッセージ` を使うと試合内の全員に送信できます。

## TNTRun

足元の床が消えていく中で、落ちずに最後まで走り続ける生き残りゲームです。

![](/images/seesaa/b40e061d6f9b6fdb.webp)

### 参加方法と遊び方

1. `/tntrun list`（別名 `/tr`）で会場一覧を確認します。
2. `/tntrun join アリーナ名` を実行するか、ロビーの参加看板を右クリックして参加します。
3. 試合が始まると、踏んだ足元の床が一定時間で消えていきます。落下や会場外への移動、致命的なダメージで脱落すると観戦になります。
4. 途中で退出する場合は `/tntrun leave` を実行します。
5. `/tntrun stats` で参加回数や勝利数を確認できます。

### 待機ロビーでの機能

- **開始投票**: 待機中に `/tntrun vote` を実行するか、インベントリのダイヤモンド(VOTE)をクリックすると開始カウントダウンに投票できます。
- **ダブルジャンプ**: `/tntrun shop` を実行するか、ネザースター(SHOP)をクリックしてダブルジャンプを購入できます。
  - 地面にいる状態でジャンプキーを連続して押すと発動します。
  - 未使用分は通常10回まで所持可能で、次の試合へも持ち越されます。
- **情報・統計**: エメラルド(INFO)で案内、レッドストーン(STATS)で戦績、ベッド(LEAVE)で退出できます。
- **パーティー**: `/tntrun party create` でパーティーを作成し、`/tntrun party invite 名前` で招待できます。

## スロット（カジノ）

運営が設置したスロット台や対象エンティティを右クリックし、画面のレバーを押して遊びます。

![](/images/seesaa/23f8ad553d3b4d3e.webp)

- 料金はスロット台に表示されます。台によっては景品一覧も確認できます。
- 画面を閉じても抽選は継続して行われます。
- 料金を支払う前に、景品を受け取れるよう持ち物に十分な空きを作っておいてください。

## 肝試し

探索者と鬼に分かれて館内を探索する脱出系ホラーゲームです。

- **参加予約**:
  - `/joingame normal`: 探索者として参加予約します。
  - `/joingame hunter`: 鬼（ハンター）希望で予約します（開始時に鬼になる確約ではありません）。
  - `/leavegame`: 開始前の予約を取り消します。
  - ゲーム開始には3〜10人のプレイヤーが必要です。
- **探索者のルール**:
  - 配られた地図が示す目的地を探します。正しい目的地に到達すると地図を1枚消費し、発見ポイントが1増えて次の目的地が指示されます。間違った場所に立ち入るとダメージを受けます。
  - 走ったり跳んだりするとスタミナが減少します。「[スタミナ切れ]」「[スタミナ回復中]」「[スタミナ全回復]」の表示を確認しながら進んでください。味方の近くにいると体力が徐々に回復します。
- **鬼のルール**:
  - ゲーム開始30秒後に出発し、探索者を捕まえます。探索者を捕まえるとキルポイントが3増えます。
- **勝敗**:
  - 制限時間は15分です。時間切れになると探索者の勝利、探索者が全滅すると鬼の勝利となります。
  - `/points` で現在のポイントと累計イベントポイントを確認できます。
  - 終了後はロビーへ戻り、参加前の持ち物や状態が復元されます。

## 困ったとき・エラーメッセージ

ミニゲーム中にエラーが表示された場合は、以下の内容を確認してください。

| 表示 | 意味・対応 |
|---|---|
| `現在、あなたの抽選タスクが実行中です。完了をお待ちください。` | ルーレットの抽選が終わるまでお待ちください。 |
| `クールダウン中です。あと N 秒お待ちください。` | ルーレットの待ち時間中です。指定秒数お待ちください。 |
| `このサイコロは他のプレイヤーのものです。` | サイコロを投げた本人だけが回収できます。 |
| `PvP は無効です。` / `BedWars は無効です。` / `TNTRun は無効です。` | そのゲームは現在利用できません。運営の設定を確認してください。 |
| `BedWars: 有効な招待がありません` | 招待が期限切れ、取り消し済み、または指定した相手が違います。 |
| `先に /tntrun leave で退出してください。` | TNTRun参加中は他のコマンドが制限されます。先に `/tntrun leave` で退出してください。 |
| `PvP の復元が未完了です。` / `BedWars の持ち物復元が未完了です。` / `前回ゲームの復元処理が完了していません。` | 参加前の状態復元に問題が発生しています。再接続しても解決しない場合は運営へご連絡ください。 |
| `未解決の取引があります。管理者に連絡してください。` | スロットの前回取引が未解決の状態です。運営へご連絡ください。 |
