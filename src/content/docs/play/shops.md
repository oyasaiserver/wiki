おやさいサーバーでは、公式のショップやプレイヤーが自由に開くことができる「看板ショップ」（OyasaiSignShop）を通じて、アイテムの購入や売却を行うことができます。

## 主要なショップ

### 中央商店街

おやさい中央商店街は、経済の中心地として各種のアイテムが揃っています。
比較的新しく、出店が続き品ぞろえも拡大中です。
headやバナーなど痒い所に手が届くアイテムも勢ぞろいしています。

- **販売中**: 革製品、染料、ツール、アルファベットの旗、移動手段 など
- **買取中**: 各種鉱石
- スポーンからゲートを通って行くことができます。

![](https://image01.seesaawiki.jp/o/i/oyasai/qaL9hiszFp.png)

### 地下街

最初期からの伝統あるショップ街です。
中央商店街にない珍しいアイテムも手に入ります。

- **販売中**: 各種作物、head、防具、染料
- `/sltp -10813` で地下街の入口にテレポートできます。

## 看板ショップ（OyasaiSignShop）

プレイヤーは看板とチェストを使って自分のお店を開くことができます。
また、看板を右クリックするだけで手軽にアイテムを購入・売却できます。

店の種類は `/signshop list` でも確認できます。

### 店の種類

看板の1行目に書かれている文字によって、店の種類が分かれています。

| 看板の1行目 | 右クリックしたときの動作 |
|---|---|
| `[Buy]` | お金を店主に支払い、店のチェストから商品を受け取ります（プレイヤーの販売店） |
| `[Sell]` | 商品を店のチェストへ納品し、店主からお金を受け取ります（プレイヤーの買取店） |
| `[iBuy]` | お金を支払い、商品を受け取ります（公式ショップ。在庫は減りません） |
| `[iSell]` | 商品を納品し、お金を受け取ります（公式ショップ。チェストには入りません） |
| `[Device]` | お金を店主に支払い、店のレバーを10秒間ONにします |

- 1回の取引でやり取りされる商品は、店ごとに設定された組み合わせ（例: ダイヤ64個など）です。
- 商品の名前やエンチャントなどが見本と完全に一致しているものだけが対象になります。
- 持ち物は、防具欄・オフハンドを除いたメインインベントリ36枠を使用します。

### 取引の前に確認する（左クリック）

道具などを持たずに看板を**左クリック**すると、現在の取引可能状態を確認できます。

表示例: `種類 / 商品: DIAMOND x64 / 価格: 100円 / 取引可能`

最後の部分が「取引可能」と表示されていれば取引できます。

| 表示 | 意味 |
|---|---|
| `品物または空き容量が不足` | 店の在庫・店の箱の空き容量・自分の商品・自分のインベントリの空きのいずれかが不足しています |
| `レバーを使えません` | Device店のレバーが現在ONになっているか、見つかりません |
| `停止中: 理由` | 店が停止されています。運営へご連絡ください |
| `見本を読めません` | 店の商品データに問題が発生しています |
| `未登録` | 店として登録されていない看板です |

※看板1行目の文字色は、青なら取引可能、赤なら取引不能の目安です（取引や再読み込み時に更新されます）。

### 取引をする（右クリック）

看板を**右クリック**すると、取引を実行します。

- 「取引が完了しました」と表示されれば成功です。
- 取引に失敗した場合はお金やアイテムは元の状態に戻ります。
- **「取引結果の確認が必要です。運営に連絡してください」** と表示された場合は、結果が確定していません。**同じ店を連続して使わず**、運営へ連絡してください。
- `[Sell]` で「残高が足りません」と出た場合は、**店主のお金**が不足しています。

### 店のチェストと保護

- 店に登録されたチェストや樽は、店主（および運営）しか開けたり壊したりできません。他の人が開こうとすると「この店のチェストは店主だけが開けます」と表示されます。
- 看板を支えているブロックは誰も壊せません。看板を店主が壊すと店ごと削除されます。
- チェストからホッパーで中身が吸い出されるのを防ぐには、チェストに施錠コマンド `/lock` を設定してください（詳細は [土地の保護について](/rules/land-protection/) を参照）。

### 店の作り方（上級ランク以上）

店を作成するには権限（上級ランク以上）が必要です。作成権限がない場合は「作成権限がありません」と表示されます。

![](https://image02.seesaawiki.jp/o/i/oyasai/8cbcf6c655968df3.png)

1. 看板を設置し、**1行目**に `[Buy]` などの種類、**4行目**に値段（例: `100`、`1,200`、`¥100`、無料なら `0`）を書きます。2行目と3行目は説明文（商品名など）を自由に記入できます。
2. 紐付ける箱（チェスト、トラップチェスト、樽、シュルカーボックス）またはレバー（Deviceの場合）を、**レッドストーンの粉を持って左クリック**します。「対象を選びました」と表示されます（看板と同じワールド内で最大100個まで選択可能）。
3. **1つ目に選んだ箱**の中に、1回の取引で売り買いする商品を入れます。箱に入っている中身すべてが1回分の取引対象になります。
4. レッドストーンの粉を持ったまま、設置した看板を**左クリック**します。「店を作成しました」と出れば完成です。

![](https://image01.seesaawiki.jp/o/i/oyasai/f39e42d93edf216b.png)

> [!WARNING]
> 一度選んだブロックの選択を取り消すコマンドはありません。店を完成させるかサーバーが再起動するまで選択状態が残ります。かまど・ホッパー・ディスペンサー・銅のチェストなどは店に使用できません。

### 店の変更・確認・削除

| やりたいこと | 操作方法 |
|---|---|
| 商品や値段を変更する | 箱の中身や看板4行目を修正した後、**イカスミ**を持って看板を左クリックします（紐付ける箱を変更する場合は、先にレッドストーンで選び直します） |
| 店の情報を確認する | **本と羽ペン**を持って看板を左クリックします |
| 店を削除する | **金のオノ**で看板を破壊します |

- 変更や削除は店主本人のみ行えます。
- 店のチェストを店主が壊すと、その店は**停止**状態になります。再開するには残りのチェストをレッドストーンで選び直してから看板を左クリックします。

### 困ったとき（作成時のエラー）

| 表示 | 意味 |
|---|---|
| `値段を読めません` | 看板4行目の値段の形式が正しくありません。 |
| `対象は同じ世界から100個以下で選んでください` | 箱が選択されていない、選びすぎている、または別ワールドのブロックが選択されています。 |
| `LWC の許可を確認できません` | 選択したブロックが他人の保護下にあるか、未読み込みエリアにあります。 |
| `箱またはレバーの選択が正しくありません` | Deviceなのにレバーがない、または通常の店なのに箱が選択されていません。 |
| `見本の品がありません` | 1つ目に選んだ箱が空です。 |
| `店主ではありません` | 他人の店を変更することはできません。 |
