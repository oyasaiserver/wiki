おやさいサーバーでは、サーバー内通貨である「**円**」と、投票や建築評価などで獲得できる「**トークン（ポイント）**」という2種類の通貨が使われています。

これらを使って、メニューショップやプレイヤーショップで建材・アイテムを購入したり、他のプレイヤーと取引したりできます。

## 通貨とお金（円）

### 最初の残高

初めておやさいサーバーに参加したときに自動で銀行口座が開設され、初期費用として **¥10,240** が付与されます。

### お金のコマンド

| コマンド | 別名 | できること |
|---|---|---|
| `/balance` | `/bal`、`/money` など | 自分の所持金を確認します |
| `/pay <プレイヤー名> <金額>` | `/epay` | 自分の残高から他のプレイヤーに送金します |
| `/balancetop [ページ]` | `/baltop` | 所持金ランキングを10人ずつ表示します |

### 送金のルールと注意点

送金を行う際は、以下の点に注意してください。

- **確認なしで即確定**: `/pay` を実行すると確認画面なしですぐに送金が確定し、取り消すことはできません。
- **相手への通知はありません**: 送金に成功しても、**受け取った側のプレイヤー画面には通知が表示されません**。送金した旨はチャットなどで直接相手に伝えてください。
- **金額の指定**: 金額は数字で入力します（`1,000` や `¥1,000` の形も可能）。小数は四捨五入され、1円未満やマイナスの送金はできません。
- **相手の状態**: 相手がオフラインのときは原則送金できません。また、相手の残高が上限（10兆円）を超える場合も送金できません。

### お金に関する困ったとき

| 表示 | 意味・対処 |
|---|---|
| `経済は現在利用できません。` | お金の機能が一時停止しています。時間をおいて試してください。 |
| `相手の口座がありません。` | 相手の名前の綴りを確認してください。 |
| `オフラインの相手には送金できません。` | 相手がサーバーにログインしてから送金してください。 |
| `金額は 1 円以上にしてください。` | 1円以上の数字を指定してください。 |
| `送金に失敗しました。残高と上限を確認してください。` | 自分の残高不足や相手の所持金上限などを確認してください。 |

## トークン（OyasaiToken）

投票や各種イベントなどで獲得できる特別な通貨（ポイント）です。
ポイントショップでの限定アイテム購入や、匠ランクでの個人ワールド拡張などに使用します。

### トークンのコマンド

| コマンド | 説明 |
|---|---|
| `/token`（または `/token balance`） | 自分のトークン残高を確認します |
| `/token send <プレイヤー名またはUUID> <数量>` | 他のプレイヤーにトークンを送金します |
| `/token top [件数]` | トークン所持数のランキングを表示します（初期値10件、最大50件） |

### トークン送金のルール

- 数量は正の整数で指定します。送金額に上限が設定されている場合があります。
- 相手がオフラインでも送信できますが、入力した名前の誤りを取り消すことはできません。送信前に名前をよく確認してください。
- 相手がオンラインの場合は相手に通知が届きますが、オフラインの相手には通知されません。

## ショップの利用

おやさいサーバーでは、主に以下の方法でアイテムの売買ができます。

- **メニューショップ（公式ショップ）**: チャット欄で `/menu` または `/shop` を入力して開くGUIショップです。建材・装飾品・鉱石売却・ポイントショップなどを手軽に利用できます。詳しくは [メニュー画面](/start/menu/) をご覧ください。
- **看板ショップ（プレイヤーショップ）**: プレイヤーがワールド内に看板とチェストを使って設置するショップです。詳しくは [ショップ情報](/play/shops/) をご覧ください。

## お金・トークンの稼ぎ方

| お金の稼ぎ方 | トークン（ポイント）の稼ぎ方 |
|---|---|
| ・資源ワールドでの採掘・売却<br>・投票サイトでの投票<br>・自分のショップを開業して商品を販売<br>・PvP アリーナの賭け | ・投票サイトでの毎日の投票<br>・SocialLikesで他の人からイイネをもらう<br>・イベントでの獲得 |

### 1. 採掘で稼ぐ

資源ワールド（資源ネザー）で採掘を行い、入手した鉱石を売却して稼ぎます。

- 鉱山ワールドでは、掘った鉱石が岩盤に置き換わり時間経過でリポップします。
- 掘った鉱石は、`/menu` の「ショップ」から売却するか、中央商店街の買取看板で売却できます。

### 2. 投票で稼ぐ（おすすめ）

投票サイトでおやさいサーバーに投票すると、毎日多額のお金と投票ポイントを受け取ることができます。
詳しくは [投票について](/play/voting/) をご覧ください。

### 3. プレイヤーショップで稼ぐ

他のプレイヤーが必要とするエンチャント本、ツール、建材、モブドロップ品などを集め、看板ショップを開いて販売します。
上級ランク以上になると自分のお店を開設できます。詳しくは [ショップ情報](/play/shops/) をご覧ください。

### 4. PvP の賭けで稼ぐ

賭けが有効な PvP アリーナでは、試合に出ていないプレイヤーが勝敗を予想して賭けることができます。詳しくは [ミニゲーム](/play/minigames/) をご覧ください。
